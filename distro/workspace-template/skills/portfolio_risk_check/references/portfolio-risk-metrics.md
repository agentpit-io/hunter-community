# 持仓组合风险暴露与压力测试指标规范

> 所有权重、回撤与压力测试数值必须来自 `portfolio` 与 `broker_*` 工具返回，缺失项填 `—`。

## 一、组合风险警戒阈值表

| 风险维度 | 指标名称 | 稳健区间 | 风险预警阈值（触发 ⚠️） |
|---|---|---|---|
| **单票集中度** | 单一标的最高持仓权重 | ≤ 用户设定上限（默认 20%） | > 用户设定上限 或 单票 > 35% |
| **行业集中度** | 前三大一级行业合计权重 | ≤ 60% | 单一行业 > 40% 或 前三行业 > 75% |
| **现金缓冲垫** | 可用现金占总资产比例 | ≥ 10%（保守型 ≥ 20%） | < 5%（满仓缺乏应对回撤弹性） |
| **估值脆弱度** | 持仓中 PE 分位 > 80% 的权重占比 | ≤ 30% | > 50%（组合整体处于历史高估值区） |
| **特殊状态暴露** | ST / \*ST / 停牌 / 减持期标的占比 | 0% | > 0%（逐只点名警示） |
