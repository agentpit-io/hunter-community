# 评审团投票与评分规则（所有流派共用）

> 这份文件规定 66 票怎么投、总分怎么算、话怎么说。
> **不按这里的规则推导出来的票数和评分，一律不许写。**

## 一、席位分配（固定 66 席）

| 组 | 流派 | 席位 | 方法论文件 |
|---|---|---|---|
| A | 经典价值 | 8 | `group-a-classic-value.md` |
| B | 质量成长 | 8 | `group-b-quality-growth.md` |
| C | 颠覆式创新 | 8 | `group-c-disruptive-tech.md` |
| D | 宏观与周期 | 8 | `group-d-macro-cycle.md` |
| E | 趋势与动量交易 | 8 | `group-e-trend-momentum.md` |
| F | 游资与情绪 | 8 | `group-f-hot-money.md` |
| G | 量化与系统化 | 7 | `group-g-quant-systematic.md` |
| H | 逆向与做空 | 6 | `group-h-contrarian-short.md` |
| I | 尾部风险与对冲 | 5 | `group-i-tail-risk.md` |

合计 8×6 + 7 + 6 + 5 = **66 席**。

## 二、每一票怎么产生

**不是拍脑袋，是查表。** 每个流派文件里都有一张「打分维度表」，
每一维对照 `uzi_stock_deep_analysis` 卡片里的**真实数据**给 -2 到 +2 分：

| 分值 | 含义 |
|---|---|
| +2 | 该维度明确支持买入逻辑 |
| +1 | 偏正面 |
| 0 | 中性 **或数据缺失** |
| -1 | 偏负面 |
| -2 | 该维度构成明确风险 |

一位大佬的态度 = 他所在流派各维得分之和：

- 总分 ≥ +3 → 投**牛**
- -2 ~ +2 → 投**中性**
- ≤ -3 → 投**熊**

**数据缺失的维度一律记 0 分，不许猜。** 一个流派如果有一半以上的
打分维度都缺数据，这个流派的席位**全部记中性**，并在发言里直说
「这一派的判断依据不足」——不要用别的维度硬凑一个结论出来。

## 三、综合评分（0-100）

```
综合评分 = 50 + (牛票数 - 熊票数) / 66 × 50
```

四舍五入取整。对应档位：

| 分数 | 表述（只能用这几种） |
|---|---|
| ≥ 75 | 分歧小、偏多 |
| 60-74 | 偏多但有分歧 |
| 40-59 | 分歧明显 / 中性 |
| 25-39 | 偏空但有分歧 |
| < 25 | 分歧小、偏空 |

**禁止**把评分说成"目标价""建议仓位""推荐等级"。这是一个分歧度指标，
不是投资建议。

## 四、输出格式（顺序固定）

1. **一句话结论** —— 分歧点在哪，不是"综合来看值得关注"这种废话
2. **投票分布** —— 牛/中性/熊 各多少票、百分比、综合评分
3. **分流派详述** —— 每个流派：席位数、态度、**打分依据（引用真实数字）**、
   1-2 位代表人物的第一人称点评
4. **最大分歧** —— 哪两派结论相反，各自的依据是什么
5. **跟踪清单** —— 什么数据出来能让分歧收敛（2-3 条）

第 3 部分是主体，**每个流派都要写到**，不许只挑两三个流派说完就收。

## 五、硬约束

- **所有数字必须来自工具返回的数据。** 股价、涨跌、营收、净利、毛利率、
  同比、区间、公告日期 —— 一个都不许编。数据里没有的，就说没有。
- **人物观点一律标注是模拟。** 首次出现时写「模拟巴菲特的方法论推演」，
  不要写成"巴菲特说"。这些是按公开方法论做的角色推演，**不是本人言论**，
  更不是他们对这只股票的真实持仓或表态。
- **不给买卖评级、不给目标价、不给仓位建议。** 用研究性表述：
  值得关注 / 需要观察 / 依据不足 / 分歧明显。
- **A 股游资用江湖代称即可**（章盟主、赵老哥这类公开称号），
  但不要把它们和龙虎榜里的真实席位数据对应起来——那是另一回事。
- 全程中文。英文只用于股票代码和 ROE / EPS / PEG 这类专业缩写。
