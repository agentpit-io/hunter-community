# UZI · 财报解读

## 什么时候用

财报刚出、或用户问「这份财报怎么样」「业绩好不好」。

用户说「简版」「三条要点」时,跳过下面第 3-5 步,只给结论层。
默认走完整流程。

## 怎么做

### 第 1 步 · 定位这是哪一期

先说清楚在解读**哪一期**(2026 半年报 / 2025 年报),以及**披露日期**。
用户常常以为在看最新的,其实数据滞后一个季度 —— 一开始就讲明白。

### 第 2 步 · beat / miss

对齐一致预期,给三行:

```
营收    实际 xx亿   预期 xx亿   +N%   beat/miss/in-line
净利润  实际 xx亿   预期 xx亿   -N%
EPS     实际 x.xx   预期 x.xx   +N%
```

**拿不到一致预期就明说"无一致预期数据,以下用同比替代"** ——
不要把同比增速伪装成 beat/miss,那是两件事:同比是跟自己比,
beat/miss 是跟市场期待比,后者才决定股价反应。

### 第 3 步 · 拆 EPS 驱动

利润变化从来不是单一原因,拆成四层看谁在起作用:

```
营收增长贡献      +x.xx
毛利率变化贡献    +x.xx   ← 提价?降本?还是产品结构变了
费用率变化贡献    -x.xx   ← 销售费用冲出去了还是研发在投
非经常性损益      +x.xx   ← **单独列出来**
────────────────────────
EPS 变化          +x.xx
```

**非经常性损益必须单独列。** 靠卖资产、政府补助、投资收益撑起来的利润,
和主营赚来的利润完全不是一回事,合在一起看会得出相反结论。

### 第 4 步 · 三张表交叉验证

只看利润表会被骗。三个必查:

| 检查 | 危险信号 |
|---|---|
| 净利润 vs 经营性现金流 | 利润涨、现金流跌 → 可能在赊账做收入 |
| 营收 vs 应收账款 | 应收增速远快于营收 → 回款在恶化 |
| 营收 vs 存货 | 存货大幅增加 → 可能卖不动了 |

**任何一条命中就要在结论里点出来**,哪怕财报整体看着漂亮。

### 第 5 步 · 指引质量

不只看指引数字,看**指引的可信度**:

- 上一期的指引兑现了吗?(连续两期不兑现 → 大幅折价)
- 这次给的是区间还是单点?区间多宽?
- 有没有从"具体数字"退回"定性表述"?那通常是在留退路

### 第 6 步 · 结论

```
一句话       这份财报的核心是什么
三个好消息   按重要性排
三个坏消息   **必须给满三个**,一份财报不可能全是好的;
             找不到三个说明看得不够细
对投资论点   原来的假设哪些被验证、哪些被证伪
```

## 硬性要求

1. **必须说清是哪一期财报、什么时候披露的**
2. 拿不到一致预期就明说,不许拿同比冒充 beat/miss
3. **非经常性损益单独列**,不许混进主营利润
4. **坏消息必须给满三个**。做不到就说"本次未发现第三条,可能是我看漏了"
5. 不许只根据利润表下结论
