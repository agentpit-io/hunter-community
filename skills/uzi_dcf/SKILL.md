# UZI · DCF 估值

## 什么时候用

用户问「值多少钱」「贵不贵」「内在价值」「目标价怎么来的」,或者要对一个
已有的估值结论做压力测试时。

**不适用**:亏损且现金流为负的早期公司、周期底部的强周期股、
金融股(银行/保险的现金流定义不同,用 DDM 或 P/B)。遇到这三类**直接说明
为什么不适用**,改用同行对标,不要硬套一个自己都不信的数。

## 怎么做

### 第 1 步 · 取数

调 `uzi_stock_deep_analysis` 拿财务与行情。至少要拿到:
近 3-5 年营收、经营性现金流、资本开支、有息负债、现金、股本、当前股价。

**拿不到就停**。缺哪一项直接说缺哪一项,不要用行业平均值顶替 ——
用假数据算出来的内在价值比不算更糟,它看起来很确定。

### 第 2 步 · 自由现金流

```
FCF = 经营性现金流 − 资本开支
```

用近 3 年均值而不是最近一年,除非有明确理由(如刚完成大额扩产)。
**说明你用了哪一年的数、为什么**。

### 第 3 步 · WACC

```
WACC = E/(D+E) × Re + D/(D+E) × Rd × (1 − 税率)
Re   = 无风险利率 + β × 市场风险溢价
```

A股取值区间(没有更好依据时):
- 无风险利率:10 年期国债,当前约 2%-2.5%
- 市场风险溢价:5%-7%
- β:同业中位数,拿不到就按行业属性取 —— 公用事业 0.6-0.8,
  消费 0.8-1.0,制造 1.0-1.2,科技/周期 1.2-1.5

**每个取值都要写明来源或理由。**「β 取 1.1」是废话,
「β 取 1.1 · 参照同业中位数,该公司收入波动略高于行业」才是可被质疑的。

### 第 4 步 · 预测期与永续期

10 年显性预测 + 永续期。增长率分三段:
- 前 3 年:按管理层指引或近 3 年复合增速,取更保守的
- 4-10 年:线性收敛到永续增长率
- 永续:**不得超过长期 GDP 名义增速**(A股按 3%-4%)。
  超过就等于假设这家公司最终会大过整个经济体

### 第 5 步 · 敏感性表(必须给)

以 WACC 和永续增长率做 5×5 网格,横轴 WACC ±1%(步长 0.5%),
纵轴 g ±1%(步长 0.5%),格子里放每股内在价值。

**这张表比那个"精确"的单一数字重要得多** —— 它让用户看见结论有多脆弱。
如果 WACC 动 0.5% 就让估值翻倍,那就明说"这个模型对折现率极度敏感,
不宜作为决策依据"。

### 第 6 步 · 结论

```
内在价值区间   X - Y 元/股(对应敏感性表的合理角落,不是最优最差)
当前股价       Z 元
隐含空间       ±N%
关键假设       三条,每条写清「如果它错了会怎样」
```

## 增量更新模式

用户说「按最新财报增量更新」时,不要重跑整个模型,而是:

1. 列出**变了的假设**:营收增速、毛利率、资本开支、管理层指引
2. 每条给出 旧值 → 新值 → 对内在价值的影响(元/股)
3. 汇总:内在价值从 X 变成 Y,主要由哪一条驱动
4. **投资论点是否需要改**:如果关键假设被证伪,直接说

增量更新的价值在于**看清是什么变了**,而不是给一个新数字。

## 硬性要求

1. **不许编数字**。任何一个输入拿不到,就在结论里写明"缺 XX,
   本次估值未包含该因素",不许用行业均值默默填上
2. **不给单点目标价**,只给区间 + 敏感性
3. **写明这不是投资建议**,DCF 对假设极度敏感,换个人算能差一倍
4. 用户如果只想要个数,也要把敏感性表给他 —— 那正是他最需要看见的东西
