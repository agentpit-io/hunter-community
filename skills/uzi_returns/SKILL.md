# UZI · 组合收益归因

## 什么时候用

用户问「我赚在哪」「为什么跑输大盘」「这段时间表现如何」。

**归因是向后看的**,目的是理解**收益从哪来** —— 是选股选对了,
还是恰好踩中了风口。这两者对未来的含义完全不同。

## 前提

需要持仓明细与买入成本。缺成本价时,只能做**区间收益归因**
(从某个日期算起),要跟用户说清楚口径。

## 怎么做

### 第 1 步 · 整体表现

```
区间              起止日期(说清楚从哪算起)
组合收益率        +N%
基准收益率        沪深300 +N%
超额              +N%
```

**必须给基准。** 单说"赚了 8%"没有意义 —— 同期大盘涨 15% 的话,
那是跑输 7%。

### 第 2 步 · 按持仓拆

```
标的      权重   个股涨跌   贡献度    占总收益
600xxx    25%    +32%      +8.0%     62%    ← Top 贡献
000xxx    15%    -18%      -2.7%     -21%   ← Top 拖累
```

贡献度 = 权重 × 涨跌幅。**注意区分"涨得多"和"贡献大"** ——
一只涨 50% 但只占 2% 仓位的票,对组合的意义远不如涨 15% 占 30% 仓位的。

### 第 3 步 · 按行业拆

看收益集中在哪个行业。如果 80% 的收益来自一个行业,
说明组合**实际上是行业押注**,不管持仓数量看着多分散。
这一点用户往往没意识到。

### 第 4 步 · 选股 vs 配置(归因的核心)

拆成两块 —— 这才是归因区别于"看收益率"的地方:

```
配置效应   = Σ (组合行业权重 − 基准行业权重) × 基准行业收益
             → 你押对了行业吗
选股效应   = Σ 组合行业权重 × (组合个股收益 − 基准行业收益)
             → 在行业内你选对了个股吗
```

结论会是这四种之一,含义完全不同:

| 配置 | 选股 | 说明 |
|---|---|---|
| + | + | 两方面都对 —— 但要看是不是运气 |
| + | − | **赚的是行业的钱**,选股能力未被验证 |
| − | + | 选股有能力,但押错了赛道 |
| − | − | 两方面都不利,需要重新审视方法 |

**「+ / −」这一格最容易被误读成"我很会选股"。** 要明确指出来。

### 第 5 步 · 结论

```
一句话      这段时间的收益主要来自什么
最大贡献    及原因(是逻辑兑现,还是行业普涨)
最大拖累    及原因(是逻辑证伪,还是行业普跌)
可复制性    这个结果**能不能重复**?
            靠一只票撑起来的、或靠单一行业的,可复制性低
```

## 硬性要求

1. **必须给基准对比**,不给基准的收益率是自我安慰
2. 区分"涨幅大"和"贡献大" —— 用贡献度排序,不是涨幅
3. **选股效应与配置效应必须拆开**,并说清结论属于四象限的哪一格
4. 归因是**向后看**的,不许据此预测未来表现
5. 缺成本价时说清用的是哪个起算日

## 需要的工具

- `portfolio_portfolio_rebalance` — 取持仓与权重
