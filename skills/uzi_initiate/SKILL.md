# UZI · 机构首次覆盖

## 什么时候用

用户第一次接触一家公司,要一份**完整介绍**。

跟「投委会备忘录」的区别:首覆是写给**不了解这家公司的人**看的,
重点是把公司讲清楚;IC Memo 是写给**要拍板的人**看的,重点是决策依据
和反方论证。用户要做决定就用 IC Memo,要先搞懂公司就用这个。

## 卖方格式(按此顺序)

### 1. 首页摘要

```
公司名 · 代码 · 当前价 · 市值 · 所属行业
评级        买入 / 增持 / 中性 / 减持
目标价      X 元(较现价 +N%)· 12 个月
估值方法    DCF / 相对估值 / SOTP · 用了哪个、为什么
```

### 2. 公司概况

- **一句话业务**:它靠什么赚钱(说人话,不要抄招股书)
- 收入结构:按业务/地区拆,给占比
- 产业链位置:上游是谁、下游是谁、议价权在谁手里
- 主要股东与实控人

### 3. 投资亮点(3-5 条)

每条的结构必须是 **观察 → 数据 → 推论**:

> **产能扩张进入兑现期**
> 2025 年资本开支 xx 亿(同比 +N%),新产线预计 2026Q2 投产,
> 满产后产能提升 N%。按当前售价与毛利率静态测算,对应营收增量 xx 亿。
> **前提是需求跟得上** —— 见风险 2。

**每条亮点都要带一个前提或反向条件。** 只写好的一面就是研报体废话。

### 4. 财务分析

三年历史 + 两年预测,给出:
- 营收与利润趋势,**增长来自量还是价**
- 毛利率/净利率趋势与同业对比
- ROE 拆解(杜邦:净利率 × 周转率 × 杠杆)—— 说清 ROE 是靠什么撑的
- 现金流质量:经营现金流/净利润 比值

### 5. 估值

至少两种方法交叉验证,并**说明两者差异的原因**:

```
DCF        内在价值区间 X-Y 元    假设见附录
相对估值   同业中位 PE xx 倍      对应 Z 元
────────────────────────────────
目标价     取 ... 元,理由 ...
```

两种方法差距超过 30% 时,**明说哪个更可信、为什么**,不要取平均。

### 6. 风险因素(3-5 条 · 必须具体)

```
❌ "宏观经济波动风险"       ← 废话,适用于所有公司
✅ "前五大客户占营收 62%,
    其中第一大客户合同 2027 年到期"   ← 这才是风险
```

每条风险给:**触发条件 · 影响程度 · 观察指标**。

### 7. 评级与目标价的逻辑

明确写出:目标价怎么来的、对应什么假设、什么情况下会调整评级。

## 硬性要求

1. **每条投资亮点必须带前提或反向条件**
2. **风险必须具体到这家公司**,通用风险一条不许写
3. 估值用两种方法交叉验证,差异大时说清楚哪个可信
4. **数据拿不到的部分明确标注**,不许用行业惯例填充
5. 结尾写明这不是投资建议
