# UZI · 同行对标

## 什么时候用

用户问「比同行贵吗」「行业平均什么水平」「该给多少倍」时。

也用在 DCF 之后做交叉验证:**两种方法给出的区间如果差三倍,
说明至少有一个的假设错了**,要说出来而不是取平均。

## 怎么做

### 第 1 步 · 选可比公司

调 `uzi_stock_deep_analysis`,同业清单来自 `a.peers`(巨潮行业分类同 l2 分组)。

**拿到之后必须自己再筛一遍**,同行业 ≠ 可比:
- 业务结构差太远的剔除(同属"计算机"的做芯片和做外包不可比)
- 市值差一个数量级的剔除
- 亏损的在算 PE 时剔除(负 PE 无意义),但算 PS/PB 时保留
- 剔了谁、为什么,**写出来**

可比公司少于 3 家就直说"可比样本不足,结论参考价值有限"。

### 第 2 步 · 选倍数

按行业属性选,不要四个都堆上:

| 行业 | 首选 | 理由 |
|---|---|---|
| 消费 / 医药 / 稳定制造 | PE、EV/EBITDA | 盈利稳定,PE 有意义 |
| 银行 / 保险 / 地产 | PB | 资产驱动,PE 受拨备扰动 |
| 亏损期科技 / 生物医药 | PS | 还没有盈利可比 |
| 重资产 / 高折旧 | EV/EBITDA | 剥离折旧与资本结构差异 |

**写清楚为什么用这个倍数**。用错倍数比不做对标更误导。

### 第 3 步 · 分位

给出该股在同业中的分位数,以及**分位背后的原因**:

```
PE(TTM)     28.5x   同业分位 75%   贵
PB          3.2x    同业分位 60%
EV/EBITDA   15.1x   同业分位 70%
```

然后回答关键问题:**溢价/折价是合理的吗?**
- 溢价合理:ROE 更高、增速更快、护城河更深、治理更好
- 溢价不合理:只是最近涨得多、或者被概念带的

这一步才是对标的价值。只给分位不解释,等于把结论留给用户猜。

### 第 4 步 · 合理区间

```
同业中位数倍数 × 该股对应财务指标 = 合理市值
再按溢价/折价理由调整 ±N%
```

给区间不给单点。并说明:如果这家公司确实该拿溢价,
用中位数算出来的"合理价"本身就是低估的。

## 硬性要求

1. **可比公司来自 `a.peers`,不足 3 家就明说**。不要自己编同行
2. 倍数用 TTM,不用静态;用了哪个口径要写
3. **不要把四个倍数的结论平均**。它们不一致时,说清哪个更可信、为什么
4. 与 DCF 结论差距过大时,**明说两者矛盾**,不要和稀泥

## 需要的工具

- `uzi_stock_deep_analysis` — 取财务、行情、同业清单
