# UZI · 杀猪盘排查

## 什么时候用

- 用户说「这只票有人推荐给我」「群里在喊」「最近涨得很凶」
- 一只没听过的票突然大涨
- 买入前的最后一道检查

**这个 SKILL 的立场是有偏的:它专门找坏迹象。** 找不到不等于安全,
只等于"没有命中这些特定模式"。这一点结论里必须写明。

## 五类信号

逐类检查,每类给"命中/未命中/数据不足"。**不许因为数据缺就跳过不提。**

### ① 价格与基本面脱节

```
近 3 个月涨幅        vs   同期营收/利润增速
近 3 个月涨幅        vs   同行业平均涨幅
当前 PE/PB 分位      vs   历史与同业
```

危险:股价翻倍而基本面无变化、且显著跑赢同行 —— 涨的是故事不是业绩。

### ② 股东与内部人行为(**最硬的信号**)

- 大股东/高管**在上涨期间**减持 → 高度危险
- 股权质押比例高(>50%)且股价在高位
- 限售解禁临近
- 实控人频繁变更

**"内部人在卖,外面在喊买"是杀猪盘最稳定的特征。** 数据来自
`a.governance` 与公告 —— 拿不到就明说拿不到,这条空着风险很大。

### ③ 财务造假迹象

| 检查 | 危险信号 |
|---|---|
| 净利润 vs 经营现金流 | 利润高增、现金流为负或大幅背离 |
| 应收账款 vs 营收 | 应收增速远超营收 |
| 毛利率 vs 同业 | 显著高于同业且无法解释 |
| 其他应收款/其他流动资产 | 异常膨胀(常见的资金占用藏身处) |
| 审计意见 | 非标意见、更换会计师事务所 |

### ④ 交易特征

- 龙虎榜频繁出现游资席位(`a.lhb`)
- 换手率异常高但股价横盘 → 可能在派发
- 涨停/跌停频繁,分时图有明显对倒特征

### ⑤ 舆论热度

- 突然出现大量荐股内容、"内幕消息"、"重组预期"
- 消息源不可考(自媒体、群、短视频),无公告支撑
- **公司本身对传闻不予澄清**

## 结论格式

```
预警等级    🔴 高 / 🟡 中 / 🟢 低 / ⚪ 数据不足以判断

命中信号    逐条列出,每条给具体数据
未命中      也要列,让用户看到检查了哪些
数据缺口    哪几类没查到,**这部分的风险未被评估**

一句话      如果只能说一句
```

## 硬性要求

1. **五类全部要有结论**,包括"数据不足"。跳过不提 = 让用户以为已经查过
2. 每条命中信号必须给**具体数据**,不许写"股价异常波动"这种空话
3. **绝不给"可以买/不能买"**。这个 SKILL 只报告风险信号,决策是用户的
4. 结论里必须写明:**未命中不等于安全**,只等于没命中这几类特定模式
5. 涉及具体公司的指控要谨慎措辞 —— 说"存在 XX 特征",不说"该公司造假"
