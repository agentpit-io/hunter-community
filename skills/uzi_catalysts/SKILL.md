# UZI · 催化剂日历

## 什么时候用

用户问「接下来有什么事」「什么时候买入合适」「有没有风险事件」,
或者在决定持有周期时。

## 怎么做

### 第 1 步 · 分类收集

按**确定性**分三档 —— 这比按时间排更有用:

```
确定日期     财报披露、股东大会、解禁、除权除息、债券到期
大致窗口     行业会议、政策发布期(如两会、行业规划)、产品发布季
可能发生     并购传闻、订单落地、产能投产
```

**确定的和传闻的绝不能混在一张表里。** 用户会把传闻当成日程安排。

### 第 2 步 · 逐条给影响判断

只列日期没有价值,每条要答:**这件事发生了会怎样,不发生又会怎样**。

```
日期        事件            方向    量级   为什么
2026-10-28  三季报          双向    高     关注新产线是否体现在营收
2026-11-15  限售解禁        偏空    中     解禁 xx 万股占流通盘 N%,
                                          但持有方是长期战投,减持概率低
2026-12-??  行业政策窗口     偏多    未知   传闻,无官方时间表 ← 不要当日程
```

**方向要敢给,但量级要诚实。** 说不准就写"未知",不要用"存在不确定性"含混过去。

### 第 3 步 · 特别处理解禁

解禁是最常被误读的:光看解禁数量没意义,要看**谁在解禁**。

- 战略投资者/实控人 → 减持概率低,影响被高估
- 财务投资者/PE → 减持概率高
- 员工持股 → 看成本价与当前价的差距

**解禁量占流通盘的比例**比绝对股数重要。

### 第 4 步 · 结论

```
最需要盯的一件事    及日期
风险窗口            哪一段时间事件密集、方向偏空
空窗期              如果未来 60 天没有实质催化剂,**直接说没有** ——
                    这本身是重要信息:股价缺乏向上的触发器
```

## 硬性要求

1. **确定日期 / 大致窗口 / 可能发生 三档分开**,传闻不许当日程
2. 每条给影响判断,说不准就写"未知",不许用"存在不确定性"糊弄
3. 解禁要看**是谁在解禁**和**占流通盘比例**,不是只报股数
4. **没有催化剂就说没有**,不要为了凑满日历把无关事件塞进来
5. 日期拿不到确切的就标"待定",不许估一个
