# UZI · LBO 测试

## 什么时候用

**不是**为了真的去收购。LBO 在二级市场的用途是**估值下限的压力测试**:

> 一个理性的 PE 买家,在合理杠杆和回报要求下,最多愿意为这家公司付多少钱?

这个价格通常是股价的**硬底**——低于它,产业资本或 PE 就有动力来买。
所以 LBO 的结论不是"该不该买",而是"跌到哪儿会有人接盘"。

**不适用**:现金流不稳定的周期股、资本开支极重的成长期公司、
已经高杠杆的公司(没有加杠杆空间)。这三类直接说明为什么不适用。

## 怎么做

### 第 1 步 · 判断标的适不适合杠杆

先答这四问,任何一条为否就要在结论里标出来:

1. 经营性现金流是否稳定为正(近 3 年)?
2. 资本开支占营收比是否低于 10%?
3. 现有净负债/EBITDA 是否低于 3x?
4. 业务是否可预测(非强周期、非单一大客户)?

**四条全不满足还硬做 LBO,算出来的 IRR 是数字游戏。**

### 第 2 步 · 进入假设

```
进入 EV      = 当前市值 + 净负债,再加 20%-30% 收购溢价
杠杆         债务/EBITDA 4x-6x(A股信贷环境偏紧,取下限更现实)
股权出资     EV − 债务
利率         6%-8%
```

每个取值写明理由。A股很少有真实 LBO 案例,**杠杆假设要比美股保守**,
这点要在结论里说明。

### 第 3 步 · 5 年运营

逐年推:
- EBITDA 按保守增速(不要用管理层指引,用近 3 年实际的下沿)
- 自由现金流优先还债
- 逐年算净负债与杠杆倍数

如果第 5 年杠杆还降不到 3x 以下,说明**这个杠杆结构本身不可行**,
要回去调低杠杆重算,而不是继续往下算 IRR。

### 第 4 步 · 退出与回报

```
退出 EV  = 第 5 年 EBITDA × 退出倍数
退出倍数 **不得高于进入倍数** —— 假设未来估值扩张是最常见的自欺
股权价值 = 退出 EV − 剩余净负债
MoM      = 退出股权价值 / 初始股权出资
IRR      = MoM^(1/5) − 1
```

### 第 5 步 · 结论

```
IRR         N%      (PE 门槛通常 20%-25%)
MoM         N.Nx    (5 年 2x 是及格线)
隐含收购价   X 元/股  ← **这才是二级市场关心的数**
当前股价     Y 元
安全垫       (X−Y)/Y
```

如果 IRR 达不到 20%,结论是「**当前价格对 PE 买家没有吸引力**」——
这本身就是有用的信息:说明股价没有被低估到会引来产业资本的程度。

## 硬性要求

1. **退出倍数不得高于进入倍数**。想不通就用相同倍数
2. 每一步的假设都要写明来源;A股的杠杆假设要比美股保守并说明
3. **结论落在"隐含收购价"上**,不是 IRR。用户是二级市场投资者,
   IRR 对他没有直接意义,"跌到多少会有人接盘"才有
4. 标的不适合杠杆时**直说不适合**,不要为了产出而产出
