# UZI · 尽调清单

## 什么时候用

准备重仓、或长期持有前的系统性检查。

跟「杀猪盘排查」的区别:**那个专找坏迹象、快而偏**;这个是**全面体检、
慢而中立**。要快速排雷用那个,要建立完整认知用这个。

## 用法

逐项走完 21 条,**每条必须给四样**:

```
结论      ✅ 通过 / ⚠️ 需关注 / ❌ 存在问题 / ⚪ 数据不足
证据      具体数字或公告出处
风险等级   高 / 中 / 低
后续动作   需要进一步查什么(仅在非✅时)
```

**⚪ 数据不足是合法结论,而且必须用。** 把查不到的写成"通过"是这份
清单最容易出的错 —— 21 条全绿的尽调报告基本可以判定没认真做。

## 工作流一 · 财务(6 项)

1. **收入质量** — 营收增长 vs 经营现金流是否同步;应收账款周转是否恶化
2. **利润质量** — 扣非净利占比;非经常性损益的来源与可持续性
3. **现金流** — 近 3 年经营现金流是否持续为正;自由现金流趋势
4. **负债结构** — 有息负债/EBITDA;短期债务占比;是否有集中到期
5. **资产质量** — 商誉占净资产比例;存货与应收的减值计提是否充分
6. **审计** — 审计意见类型;是否更换过会计师事务所及原因

## 工作流二 · 法律与合规(4 项)

7. **诉讼** — 重大未决诉讼金额与性质
8. **监管** — 近三年是否收到监管问询函、警示函、处罚
9. **股权** — 实控人是否明确;股权质押比例;是否有代持或一致行动人纠纷
10. **关联交易** — 占营收比例;定价是否公允;是否存在资金占用

## 工作流三 · 运营(4 项)

11. **客户集中度** — 前五大客户占比;是否有单一客户依赖
12. **供应商集中度** — 同上;关键原材料是否可替代
13. **产能与开支** — 产能利用率;在建工程规模与投产节奏
14. **核心资产** — 专利/牌照/特许经营权的有效期与续期风险

## 工作流四 · 管理层(4 项)

15. **兑现记录** — 过往三年指引 vs 实际达成
16. **利益一致性** — 高管持股比例;股权激励的考核目标是否严格
17. **稳定性** — 近三年核心高管变动
18. **信息披露** — 是否及时、是否有过财务重述

## 工作流五 · 行业与竞争(3 项)

19. **行业趋势** — 处于扩张还是收缩;政策方向
20. **竞争地位** — 市占率变化趋势(比绝对值重要)
21. **壁垒** — 护城河来源;近三年是否被削弱

## 结论格式

```
总览      ✅ N 项 · ⚠️ N 项 · ❌ N 项 · ⚪ N 项
红线      有没有"一票否决"级问题(如非标审计意见、实控人失联、
          资金占用)—— 有的话放在最前面
关注点    ⚠️ 里最重要的三条
数据缺口   ⚪ 的那几项,以及它们分别掩盖了什么风险
```

## 硬性要求

1. **21 条一条都不能跳**。查不到写 ⚪,不许略过
2. 每条都要给**具体证据**,不许只写结论
3. **⚪ 的项要说明它掩盖了什么风险** —— "缺关联交易数据"本身是中性的,
   "缺关联交易数据,因此无法排除资金占用"才有用
4. 红线问题放最前面,不要埋在第 18 条
5. 不给买卖建议
