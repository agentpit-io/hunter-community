# UZI · 投委会备忘录

## 什么时候用

要做**决策**的时候 —— 不是了解一家公司,而是决定买不买、买多少。

跟「机构首次覆盖」的区别:首覆是**介绍**一家公司给不了解的人;
IC Memo 是**说服一屋子会挑刺的人**批准一笔投资。后者必须自带反方论证。

## 怎么做

### 第 1 步 · 一页纸摘要(放最前面)

投委会的人只保证读这一段:

```
标的        名称 · 代码 · 当前价 · 市值
建议        买入 / 观察 / 放弃
建议仓位    占组合 N%
目标区间    X - Y 元(对应 base 情景)
下行保护    最坏情况到 Z 元,亏损 N%
核心逻辑    一句话
最大风险    一句话
```

### 第 2 步 · 三情景

每个情景要有**具体的世界状态**,不是给数字打个折:

```
          发生条件(必须具体)              目标价    回报    概率
Bull      新产能满产 + 行业价格回升         xx 元    +N%     20%
Base      维持当前份额 · 增速向行业收敛     xx 元    +N%     55%
Bear      主要客户流失 或 政策收紧          xx 元    -N%     25%
                                                  ─────────────
                                          期望回报  +N%     100%
```

**概率之和必须为 100%,而且要说明凭什么这么分。**
「Base 55%」不是拍的,要能讲出为什么不是 40% 或 70%。

**Bear 情景不许敷衍。** 如果 Bear 只跌 5%,说明你没认真想坏情况会怎样 ——
真正的 Bear 是"论点错了"时会发生什么。

### 第 3 步 · 关键假设与证伪点

从三情景里提炼 3 条最关键的假设,每条给:

```
假设                 现在的证据      多久能验证      证伪了怎么办
主要客户不流失        近三年稳定      每季财报        减仓至 1/3
```

**「证伪了怎么办」必须提前写。** 事后再想就来不及了 ——
这是 IC Memo 区别于研究报告的地方:它包含行动预案。

### 第 4 步 · 反方论证(必写)

**站在拒绝方,写出最有力的三条反对理由。** 不是稻草人,是真正的反驳:

```
反对 1: 估值已反映乐观预期 —— PE 处于历史 85% 分位
我方回应: ... (如果回应不了,就承认回应不了)
```

一份没有反方论证的 IC Memo 会被投委会直接打回。
**如果三条反对理由里有一条你回应不了,应该在摘要里把建议从"买入"降级。**

### 第 5 步 · 仓位与执行

```
建议仓位     N%   ← 依据:期望回报 / 下行风险 / 与现有持仓的相关性
建仓方式     一次 / 分批(分几次、什么条件下加)
止损         触发条件是什么(**是逻辑证伪,不是跌了多少**)
复查节点     下次什么时候回来看
```

**止损写逻辑不写价格。** "跌 20% 止损"是在用价格代替思考;
"主要客户流失即减仓"才是论点驱动的。

## 硬性要求

1. 三情景概率之和 = 100%,且要说明分配依据
2. **Bear 情景要真的坏** —— 是"论点错了"的世界,不是打个九折
3. **反方论证必写三条**,回应不了就如实说,并相应下调建议
4. 止损条件写**逻辑证伪信号**,不写百分比
5. 摘要放最前面,一页纸能读完
