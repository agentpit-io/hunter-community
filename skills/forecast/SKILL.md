# Kronos · 走势预测

## 什么时候用

用户明确要「预测」「未来几天走势」时。

**先说清这是什么**:Kronos 是一个在 K 线序列上训练的时序模型,
它学的是**价格形态的统计规律**,不看基本面、不看消息、不看资金。
所以它给的是「按历史形态推演,接下来大概率长这样」,
**不是「这只股票会涨」**。这个区别必须在开头讲明。

## 怎么做

### 第 1 步 · 调用

调 `hunter_cap_kpred`,参数 `code` + `days`(1-30)。
这是**耗时工具**,先告诉用户在算。

### 第 2 步 · 呈现

```
日期        开      高      低      收      较昨日
2026-08-15  xx.xx   xx.xx   xx.xx   xx.xx   +N%
...
────────────────────────────────────────
最新收盘    xx.xx
N 日后      xx.xx   累计 +N%
```

### 第 3 步 · 必须同时给的三件事

**① 涨跌停约束是否生效**
A股有涨跌停,预测值经过限幅处理。如果原始预测被限幅了,说明模型
预期的波动超出了单日允许范围 —— 这本身是"模型认为会有大幅波动"的信号。

**② 与基本面是否矛盾**
如果预测方向与近期基本面/消息面明显相反,**要指出来**,不要只报数字。
例如:模型预测上涨,但公司刚发布业绩预减 —— 模型看不到这条公告。

**③ 置信度的诚实表达**
不要给"准确率 85%"这种数字,我们没有实时的回测统计。
诚实的说法是:
> 这是基于历史 K 线形态的统计推演。时序模型对**趋势延续**的刻画好于
> **拐点识别** —— 遇到消息驱动的突变,它必然预测不到。

## 硬性要求

1. **开头就讲清模型看什么、不看什么** —— 用户以为它"知道"这家公司,
   那是最危险的误解
2. 预测失败/超时就直说,**绝不用历史价格或线性外推冒充预测结果**
3. 不给"目标价",给的是**模型推演的价格路径**,措辞要区分
4. **与基本面矛盾时必须点出来**
5. 不给买卖建议

- `hunter_cap_kpred` — Kronos 预测(经 hunter 网关 · 耗时较长)
