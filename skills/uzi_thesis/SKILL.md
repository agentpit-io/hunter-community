# UZI · 投资论点

## 什么时候用

用户要「为什么买这只」「投资逻辑是什么」,或者已经持有、想知道
「当初的理由还成立吗」。

这个 SKILL 有两种模式,**看用户是第一次问还是回来复查**:
- 首次 → 建立论点
- 复查 → 追踪漂移(用户说"还成立吗""有什么变化")

## 模式一 · 建立论点

### 5 支柱

每根支柱写三件事:**当前状态 · 支撑证据 · 什么会推翻它**。
第三件最重要 —— 一个不能被证伪的论点等于没有论点。

```
① 增长      收入从哪来?量还是价?天花板在哪?
② 护城河    为什么别人抢不走?这个壁垒在变厚还是变薄?
③ 管理层    过往兑现记录如何?利益是否与股东一致?
④ 财务      现金流质量、负债、ROE 趋势
⑤ 催化      未来 6-12 个月什么事会让市场重新定价?
```

### 关键假设(必须显式列出)

从 5 根支柱里提炼 **3 条最脆弱的假设**,每条写成可验证的形式:

```
假设 1: 主业收入未来两年保持 15%+ 增速
  验证方式: 每季度财报的营收同比
  证伪信号: 连续两季低于 10%
  若证伪:   估值中枢下移约 30%,论点需重估
```

**「公司前景良好」不是假设,是废话。** 假设必须能被下一期财报证伪。

### 论点强度

给一个诚实的自评:

```
强   5 根支柱都有硬证据,3 条假设都可验证
中   有 1-2 根支柱靠定性判断
弱   核心假设无法在 12 个月内被验证 —— 这种情况直接说
     "这更像一个故事而不是论点"
```

## 模式二 · 追踪漂移

用户回来复查时,**不要重新写一遍论点**,而是逐条对照:

```
支柱       原判断         现状              状态
增长       15%+ 增速      最近两季 11%/9%   ⚠️ 减弱
护城河     专利壁垒       竞品已绕开        ❌ 破坏
管理层     兑现良好       指引连续两次未达  ⚠️ 减弱
财务       现金流健康     无变化            ✅ 维持
催化       Q4 新品        已发布,反响平淡   ❌ 落空
```

然后回答唯一重要的问题:**论点是否还成立?**

- 5 根里坏了 1 根 → 论点减弱,列出需要观察什么
- 坏了 2 根以上 → **明确说"原论点已不成立"**,不要用"需要继续观察"和稀泥
- 关键假设被证伪 → 直接说被证伪了

## 硬性要求

1. **每根支柱都要写"什么会推翻它"** —— 没有这一条,论点就是自我强化的信念
2. 关键假设必须**可被下一期财报证伪**,写不出验证方式的假设删掉
3. 追踪模式下,**坏了就说坏了**。投资论点最大的价值是及时承认错了,
   而不是找理由维持原判
4. 不给买卖建议,只说论点成不成立
