# 自选股排序

## 什么时候用

用户问「排序」「谁最好」「哪几只最强」「分 X 个月/年前景」时用。

**关键判定**:只要用户想**横向对比多只股**(不管是所有自选还是指定几只),
都走这个 tool。**不要**为每只股逐一调 `stock_deep_analysis`(那样串行 5+ 分钟
且不能横向对比)。

## 怎么做

调 `watchlist_watchlist_rank` 一次拿全部结果:

- 用户明确说了时段(如"分 3 个月和 6 个月"),传对应 `horizons`
- 用户没说时段,或说"排序/前景",默认 4 档全展开(不传 `horizons` 即可)

拿到结果后:

1. **直接把 `markdown` 字段展示给用户** —— 这是服务端 LLM 已按结构化打分表合成好的
   排序报告(含表格 + 综合分说明 + 方法学声明)
2. **不要自己再复述打分逻辑或表格内容** —— 用户已经看到了
3. **可以补一句**:如果用户对表里某只股特别感兴趣,可以再对**那一只**跑
   `uzi_stock_deep_analysis`(深度分析每股 30-60s,不适合批量,但对单股有价值)

## 打分口径(仅内部理解,不必转述给用户)

| 时段 | 分数范围 | 打分维度 |
|-----|--------|---------|
| 3M | −4 ~ +4 | MA20/MA60 · 价 vs MA20 · 5 日量比 · 5 日动量 |
| 6M | −3 ~ +3 | MA60/MA120 · 52 周分位 · 60 日动量 |
| **1Y** | **−4 ~ +4** | **最新 ROE + 5 期 ROE 均值 + ROE 趋势 + 营收/净利同比 · 基于财报** |
| **3Y** | **0 ~ +4** | **12 期 ROE 均值 · ROE 稳定性 · 3 年 EPS CAGR · 12 期毛利率均值** |

**综合分** = 短中期(0.5) + 1Y 基本面(0.3) + 3Y 长期(0.2) · 缺失维度按可用权重归一化

## 数据缺失的处理

- 某支股拉不到数据(has_data=false):排最后,标"数据不足",不装作能排
- **A 股 1Y/3Y** 走 finance-data 财报(25 期季报,`du_return_on_equity` /
  `inc_revenue_rate` / `inc_net_profit_rate` 等) · 上游稳定,基本都能出分
- **港股 1Y/3Y** finance-data 当前无财报数据 · tool 返回时会标
  `1Y 展望 = 技术偏X · 仅技术` / `3Y 展望 = 需长期财报` · 不要装作能量化
- **不要**用"数据未 seed"这种内部术语

## 注意

- 自选股为空时,提示用户先添加,不要报错
- 只陈述排序 + 打分,不给"买入/卖出/增持/减持"评级
- 若 markdown 字段是"*(LLM 合成失败 ...)*",直接把 `scored` 结构化数据
  以表格形式转成 markdown 给用户 —— 数据本身是好的,只是 LLM 那次没合成上
