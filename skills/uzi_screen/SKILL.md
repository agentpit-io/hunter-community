# UZI · 量化筛选

## 什么时候用

用户问「这只票属于什么风格」「适合什么策略」「量化会选它吗」。

**这个 SKILL 回答的是"这只股票长什么样",不是"该不该买"。**
同一只票在价值策略里落选、在动量策略里入选,是完全正常的 ——
那说明它是一只贵但有势的票,这个判断本身就有用。

## 五套因子

每套给:**指标值 · 同业分位 · 入选/落选 · 原因一句话**。

### ① 价值

```
PE(TTM) · PB · PS · EV/EBITDA · 股息率 · 自由现金流收益率
入选门槛(相对):估值指标处于同业后 30% 分位
```

注意:低估值可能是**价值陷阱**。命中价值因子时,要顺带看
"便宜是因为被低估,还是因为基本面在恶化"。

### ② 成长

```
营收 3 年复合增速 · 净利 3 年复合增速 · 最近两季营收同比
入选门槛:营收增速 > 20% 且未出现连续下滑
```

注意:增速要看**是否在减速**。30% 但从 60% 掉下来的,
和 25% 且稳定三年的,不是一回事。

### ③ 质量

```
ROE · ROIC · 毛利率稳定性 · 经营现金流/净利润 · 资产负债率
入选门槛:ROE > 15% 且经营现金流/净利润 > 0.8
```

**质量因子是最不容易骗人的一套** —— 现金流和 ROE 长期造假成本很高。
五套里如果只能看一套,看这套。

### ④ 动量

```
近 1/3/6/12 月涨跌幅 · 相对行业超额 · 距 52 周高点距离
入选门槛:6 月与 12 月动量均为正,且跑赢行业
```

注意区分**趋势动量**和**消息脉冲**:靠一条消息拉起来的不算动量。

### ⑤ 低波

```
近 1 年日收益波动率 · 最大回撤 · β
入选门槛:波动率处于同业前 30%(即最低的那批)
```

## 结论格式

```
风格画像     入选 N/5 套 —— 属于「XX 型」
             (如:入选质量+低波,落选价值+成长 → 稳健但不便宜的白马)

逐套明细     每套:指标 · 分位 · 入选与否 · 一句话原因

矛盾之处     若同时入选价值和动量(便宜且在涨)→ 少见,值得深看
             若五套全落选 → **直说"该股不符合任何一套主流量化风格"**,
             这是有用的结论,不是失败

数据缺口     哪些指标没算出来,影响了哪一套的判断
```

## 硬性要求

1. **五套全部要有结论**,包括数据不足
2. 分位数要基于**同业**而不是全市场 —— 银行的 PB 和科技股的 PB 没有可比性
3. **入选价值因子时必须检查是不是价值陷阱**;入选成长时必须看是否在减速
4. 五套全落选就直说,不要硬找一套勉强算入选
5. 这是风格画像,**不是买卖信号**,结论里写明
