## 产品介绍

HunterCode 社区版是一套可以完全跑在自己服务器上的 AI 投研助手，覆盖 A 股、港股与美股。它把行情数据、选股筛选、回测与自然语言对话放在同一个界面里，你的持仓、自选和对话记录都只存在这台机器上。

首次打开会进入一个五步配置向导：输入初始化口令 → 环境自检 → 选择大模型 → 填入并当场测试 API Key → 选择数据供给方式。整个过程不需要改任何配置文件。

## 主要功能

- **自然语言投研对话**：直接问「最近有哪些低估的红利股」「帮我看看这只票的基本面」，助手会调用行情、财报、新闻等工具后作答。
- **魔法筛选器**：用一句话描述条件即可筛股，支持 A 股、港股、美股。
- **自选与持仓跟踪**：自选股变动、事件与信号统一推送到对话里。
- **自带大模型适配层**：支持任何 OpenAI 兼容接口（DeepSeek、通义、Kimi、OpenAI、Anthropic 等），模型配置入库后热生效，不用重启容器。
- **可扩展的 SKILL**：内置投研 SKILL 随镜像分发，也可以在界面里新建自己的 SKILL。
- **数据与对话本地化**：对话正文、自选、持仓、导入的数据包都落在本机持久化目录里。

## 安装说明

- **初始化口令**：安装表单里的「首启向导初始化口令」默认自动生成随机值。装完在「应用 → 参数」里可以随时查看明文，第一次打开站点时向导的第 0 步要用它。
- **智能交易（模拟盘）**：应用同时带一套智能交易服务 —— `paper` 持有**只追加**的模拟账本（唯一能写账本的服务），`temporal` 是交易链唯一的上层调度权威，`fin-worker` 把策略意图经 `paper` 的 HTTP 落成成交。账本库运行期角色的口令由表单的「账本库角色口令」字段生成，`fin-init` 一次性服务会在 api 迁移建出角色后自动设置，无需人工干预。
- **创建管理员**：本应用以多用户模式运行，走完向导后按提示注册账号，**第一个注册的账号就是管理员**；建好之后建议把「注册策略」改成 `closed` 再重建容器。
- **对外访问**：只有 Web 服务映射到宿主端口（默认 3180），数据库、缓存与内部服务都不对外暴露。建议再用面板的「网站」功能反向代理并开启 HTTPS。
- **资源要求**：最低 2 核 3 GB，推荐 2 核 6 GB；磁盘预留 10 GB 以上（十个容器镜像合计约 4 GB，其中智能交易的 temporal 占一部分）。首次安装需要从 GHCR 拉镜像，视网络情况可能需要几分钟。
- **备份**：所有持久化数据都在应用安装目录的 `data/` 下（`postgres` 数据库、`opencode` 对话正文、`secrets` 自动生成的密钥、`user-skills`、`packages`），直接用面板的「应用备份」即可。
- **升级**：在应用商店里选新版本升级；`data/secrets` 会被保留，因此已保存的 API Key 仍然解得开。
