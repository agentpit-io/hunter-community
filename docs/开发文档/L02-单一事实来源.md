## 八、偏离方案的决策 · 边界 · 遗留

1. **`fin_data._market_tz` 的兜底语义变了（唯一一处「值可能变」的地方，已如实记）**。旧实现在**缺 tzdata** 时静默退回固定 `EST(-5)`（那个兜底在夏天就是错的，应为 -4）；现在统一走 `market_time`，缺 tzdata 会**明确报错**（`market_time.market_tz` 的 `RuntimeError`，提示装 tzdata）。**正常镜像（装 tzdata，`python:3.11-slim` 自带，已在运行容器里实测 `ZoneInfo("Asia/Shanghai")` 可用）逐值一致**，前后对照已证。这不算「顺手修正」，是**把静默的错时区换成显式的错**，单独记在此。
2. **`db/migrations/0027_fin_control.sql` 的文件头已过时**（它还写着「真正生效的 DDL 随代码走、写在 `control.py` 的 `_DDL`」）。迁移文件**发布后不可变**（红线），故**不改它**，在此说明：现在权威就是 `0027` 本身。
3. **时段是「双镜像」而非单文件**：api / fin-worker 构建上下文隔离、不能互相 import，只能各留一份逐字节相同的实现 + parity 用例（与四期 `market_time.py` 同法）。这是本仓对「跨服务单一来源」的既定落法。
4. **本段未动的其他「同义常量」**（都**不是**时区/时段，红线 14 的射程外）：`MARKET_LABEL` / `MARKET_CURRENCY` / `CURRENCY_SYMBOL`（api `fin/markets.py` 与 paper 各一份）；paper `db.py` 的 `SET TIME ZONE 'Asia/Shanghai'`（paper 的账本会话默认时区，属另一条链）；fin-worker `config.schedule_timezone()` 的默认值。列入交接，不在本段扩。
5. **paper 的 `recon.ensure_schema` 保留**（paper 不跑迁移，这是它的启动兜底），但它已**不再自带 DDL 文本**，改 import `aux_ddl`。
