# N5 · 演示站真浏览器冒烟（2026-10-03）

对**已上线的演示站** `https://hunter-community.agentpit.io` 跑 `scripts/n5_browser_check.mjs`
（Playwright · 无头 Chromium · 1440×1000），演示站账号真登录。

> 与同级的 `N5-截图/` 不是一回事：`N5-截图/` 那批跑在**香港开发机的本地 dev 服务**（`127.0.0.1:3110`，
> 账本**有**种子数据，9/9 全过）；本目录这批跑在**演示站**，账本**为空**，
> 所以额外拍下了「空账本」状态下的页面长什么样 —— 这正是上线后第一次的真实样子。

## 结果：9 项断言 5 过 4 不过

`report.json` 是脚本原始输出（未改写）。汇总：

| 指标 | 值 |
|---|---|
| 登录 | 成功 |
| console 错误 | 0 |
| pageerror | 0 |
| 破图 | 0 |
| 横向溢出页 | 无 |

**过（5）**：市场状态条三家都在（且日历来源显示为 `hkex_official` / `nyse_official`）；
切到港股金额变 `HK$`；切回 A 股变 `¥`；自动交易页时刻表随市场切换（A 股 15:30 / 港股 16:15，
旧文案「按沪深交易日历走」已去掉）；我的账户页港股规则含 `HKD`、旧文案「本版本不提供」已去掉。

**不过（4），全部源于演示站账本为空，不是代码缺陷**：

1. **切到美股 → 金额变 `$`**：切换器本身有效（港股那步已证），但演示站无持仓 / 无估值，
   金额渲染为 `—` 而非 `$1,234.56`，正则取不到数字。
2. **跨市场合计区带汇率来源 / 时刻**：区块在（页面上有「跨市场合计（折人民币）」），
   但空账本下走的是另一条文案分支，脚本期望的三种措辞（`汇率来源` / `取不到汇率` / `合计算不出`）都没出现。
3. **报告页历史表出现「市场」列**：演示站 `fin_report` 为 0 行，页面正确显示「还没有报告」空状态，
   没有表格可断言。
4. **报告页事实行金额带币种符号**：同上，无报告。

**对照**：`N5-截图/report.json`（香港开发机、账本有数据）同一脚本 **9/9 全过**。
两边唯一变量是账本有没有数据 —— 说明这 4 项不过是被数据决定的，不是被代码决定的。

## 一处值得记的文案疑点（非阻断）

空账本下总览页同时出现「**合计可算**」标签与「还读不到任何市场的估值」，
合计值渲染为 `¥0`。三项都没得加时把合计显示成 `¥0` 而非 `—`，
和页面上「合计可算」的标签一起读，容易被当成真实合计值。建议后续在空数据分支上改成 `—` + 原因。

## 复现

```bash
N5_BASE=https://hunter-community.agentpit.io \
N5_API=https://hunter-community.agentpit.io \
N5_EMAIL=<演示站账号> N5_PASSWORD=<口令> \
N5_OUT=/tmp/n5-shots \
node scripts/n5_browser_check.mjs
```

（本机 playwright 若与缓存里的 chromium 版本不对，可给 `N5_PLAYWRIGHT` 指一个薄适配模块，
用 `executablePath` 直指缓存里的 chromium，免去为一次性冒烟下载浏览器。）
