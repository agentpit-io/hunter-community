### 2.2 §出口 2 · 点了立刻生效（请求 + 返回原文）

对**工作区代码起的真 api**（`uvicorn main:app`，天花板 `FIN_AUTO_APPLY=1`）跑一遍：点关 → 紧接着查 `/v1/fin/runtime` → 生效值变假。

```
### 项目 prj_0c32803b884f4d629ba8286f
--- GET /api/v1/fin/runtime?project_id=prj_0c32803b884f4d629ba8286f  (before)
{
  "auto_apply": true,
  "ceiling": { "memory_enabled": true, "evolution_mode": "observe", "auto_apply": true },
  "selected": { "memory_enabled": null, "evolution_mode": null, "auto_apply": null },
  "can_change": { "memory_enabled": true, "evolution_mode": true, "auto_apply": true }
}
--- POST /api/v1/fin/runtime/switch  body={switch_key:auto_apply,value:false}
{
  "changed": true,
  "new_value": false,
  "runtime.auto_apply": false,
  "runtime.selected": { "memory_enabled": null, "evolution_mode": null, "auto_apply": false }
}
--- GET /api/v1/fin/runtime?project_id=prj_0c32803b884f4d629ba8286f  (after, 紧接着、不等 5 秒)
{
  "auto_apply": false,
  "selected": { "memory_enabled": null, "evolution_mode": null, "auto_apply": false }
}
```

**读法**：默认 `auto_apply=true`（新口径 = 天花板开且未单独设置）；写入口 `changed=true` **立刻生效**
（不需要等 5 秒 TTL）；项目覆盖层记到了 `selected.auto_apply=false`。
真浏览器里同一动作也当着面验了（`r21_browser_check` A19–A22：默认 `aria-pressed=true` → 点关 → 页面「自动生效：未启用」→ `aria-pressed=false` → **后端同枪核对 `auto_apply=false`** → 再开回来）。
