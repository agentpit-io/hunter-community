## 二、`projects_for_market()` 改动后全文

```python
def projects_for_market(projects: list[dict], market: str) -> list[dict]:
    """只保留**选中集合包含该市场**的项目（P2 · 方案 §4.1）。

    判据是 `fin_project_market` 那一组市场（paper 的 `list_projects` 带出的 `markets`），
    **不是** `market_scope == market`（那表达不了 {港股,美股} 这种子集，而且 `MULTI`
    在三个市场都不匹配 = 空转）。「自由组合」要的就是：选了几个市场，就在那几个市场的
    时点各驱动一次 —— `MULTI`（集合含三个）因此**三个市场各自跑一次**，不再空转。

    **向后兼容**：`markets` 缺失（老 paper 响应）时退回单值语义（`market_scope`），
    A 股单市场项目的行为逐字节不变。`markets` 为空列表 = 「没声明过市场」→ 不驱动
    任何市场（**不回落** `market_scope` —— 回落就会把「没声明」当成 A 股）。
    """
    out = []
    for p in projects:
        mk = p.get("markets")                       # P2：paper 带出的集合
        if mk is None:                              # 兼容：老响应只有 market_scope
            mk = [p.get("market_scope") or "CN_A"]
        # paper 的 `markets` 是 `fin_project_market` 的行（对象：market/currency/…），
        # 这里取 `market` 那一列；同时容忍纯字符串（老调用方 / 测试夹手）。
        codes = [m.get("market") if isinstance(m, dict) else m for m in mk]
        if market in codes:
            out.append(p)
    return out
```

`paper.list_projects` 每项新增 `markets`（`json_agg` 子查询，固定顺序 `CN_A→HK→US`）：

```json
"markets": [{"market":"HK","currency":"HKD","initial_capital":100000.0,"opened_at":"…"}]
```

> 没有市场行的项目返回 `[]`（**不回落** `market_scope`）——本机那 2 个 P1 阻塞的 `MULTI` 历史行
> （`prj_n4_hkus` / `prj_b7791191…`）因此**不被任何市场驱动**（它们的市场集合未核实，见 P1 §六）。


   `MULTI` 项目原来**根本不会被驱动**，所以这条路径从没被走过。修法见 §三.4 #8–#10。

2. **「示例策略读行情」是有意为之，不是漏网。** 一期口径是「桥这一层不许读行情」——
   那是 A 股口径下成立的（市价单不需要价）。港美股**只接限价单**（拍板 §四），限价单必须带价，
   而「不许编数字」又不允许拍一个价 → 唯一出路是取**真实报价**（api 内部只读端点
   `GET /api/internal/fin/quote/{code}`，**不落库、无副作用**，与 paper 取快照是同一个源）。
   三个输入（参考价 / 每手 / 可用资金）全是真值，**没有一个是编的**。

3. **`market_order_supported` 落到 `fin_market_rule`（新迁移 `0037`），而不是继续写在代码里。**
   拍板 §四那张「三市场成交口径」表就是「哪个市场接市价单」的权威；让它住进「每个市场一行」的
   市场规则表，paper 与 fin-worker **读同一列**（不再各写一份 `market != "CN_A"`）。
   `CN_A=true` 沿用一期；`HK/US=false`；列缺失（未迁移的老库）退回旧口径，A 股不回归。

4. **买不起一手的市场：如实不出单，不编数量。** 10 万 HKD 档买 `00700` 一手（`100 × 421.2 = 42,120`）
   勉强够，1 万档（play）**根本买不起**——那是真实约束。示例策略按可用资金取整手，取不到就
   `halted` + 写明原因（形状与「总开关关闭」一致），而不是下一个被风控拒掉的单。

5. **现金安全垫 0.5%（`_CASH_CUSHION`）是策略的定量参数，不是市场数据。**
   用来覆盖买入手续费（港股买方约 0.136%、美股约 0.01%，口径真值在 `fin_fee_model`）。
   宁可少买一手，也不让 `funds` 风控在边界上拒单。文档里写明它是「同 `SAMPLE_LOTS` 的定量参数」。

6. **`expire` / `match-open` 也按市场**（方案没点名）。理由：`MULTI` 在每个市场各跑一遍，
   不限定市场的话，港股 16:15 收盘会把美股当天还没到收盘的挂单一起撤掉；美股时点会拿
   **隔夜的 A 股快照**撮合 A 股挂单（价格是旧的）。

7. **`get_instrument` 走 paper（账本元数据），参考价走 api（行情）**——两个源各是各自领域的权威，
   没有为了「少一个依赖」把每手股数改从行情源猜。
