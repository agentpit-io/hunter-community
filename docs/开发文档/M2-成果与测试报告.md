## 一、做了什么

### 1. 新服务 `apps/paper/`（12 个模块 + 10 个测试文件）

与 `apps/api` 同栈（FastAPI + psycopg2）、**独立镜像、独立进程**，是全仓唯一连账本库的服务。

| 文件 | 作用 |
|---|---|
| `app/config.py` | 模式 / 口令 / DSN / 实盘字段黑名单（唯一的判定处） |
| `app/db.py` | 一无连接池、一请求一事务；连接即把会话时区设成 `Asia/Shanghai` |
| `app/jsonresp.py` | 金额 `Decimal` 序列化成**字符串**（不走 `jsonable_encoder`，它会把 Decimal 变 float） |
| `app/security.py` | ① 内部口令依赖（401）② 纯 ASGI 的实盘字段守卫（400） |
| `app/selfcheck.py` | 启动自检：模式 / 口令 / 库连通 / 表齐 / **角色权限边界**，不过就 `exit 1` |
| `app/ledger.py` | 七类实体的记账：`seed_funding` / `place_order` / 现金 / 持仓 / 版本 |
| `app/valuation.py` | 估值（缺价抛 `MissingPrice`，不拿成本价顶替） |
| `app/recon.py` | 对账七项，写 `fin_recon_log`，不平打 ERROR |
| `app/schemas.py` | 请求模型，金额 `Decimal` |
| `app/risk/` | 六条纯函数 + `engine.evaluate()` |
| `app/routers/` | health / orders / projects / reference（**无任何改历史端点**） |
| `Dockerfile` `boot.sh` `requirements*.txt` `README.md` | 镜像与运行 |

**七类实体**（M-10）：`fin_project`（`version` 每笔成交 +1）· `fin_account` · `fin_order`（`source`/`actor` 可传入，默认 `ai`/`system`）· `fin_trade`（`snapshot_id NOT NULL`、写 `fee_model_version`）· `fin_cash_ledger`（追加式，每行写 `available_after`/`frozen_after`）· `fin_position`（`sellable_qty` 独立列）· `fin_valuation` + `fin_recon_log`。

**余额不存字段**：可用 / 冻结 = `fin_cash_ledger` 最后一行的 `*_after`，没有「余额列」。

### 2. 确定性风控六条（`apps/paper/app/risk/`）

| # | 模块 | 判据 | 拒绝文案（进 `fin_order.decline_reason`） |
|---|---|---|---|
| 1 | `session.py` | `fin_market_calendar.is_trading` + `sessions`，上海时区 | 「不在交易时段内（12:00 上海时间…）」 |
| 2 | `t1.py` | 卖出量 ≤ `sellable_qty` | 「可卖数量不足（T+1）…」 |
| 3 | `lot.py` | 买入 `qty % lot_size == 0` 且 `> 0`；卖出允许零股 | 「买入数量必须是 100 股的整数倍（收到 150 股）」 |
| 4 | `price_limit.py` | `fin_instrument` 的涨跌停幅度；**缺元数据即拒绝** | 「账本里没有该标的的元数据…绝不猜涨跌幅」 |
| 5 | `fee.py` | 佣金万分之 2.5（最低 5 元）+ 卖出印花税千分之 0.5 + 过户费万分之 0.1，**版本化** | 「没有可用的费用模型…」 |
| 6 | `funds.py` | 可用 ≥ 金额+费用；持仓 ≥ 卖出量 | 「可用资金不足：需要 …／持仓不足…」 |

六条都是纯函数（不连库、不取时间、不读 env）；不过者**照旧落一条 `rejected` 委托并带 `decline_reason`**，与二期人工委托同一条路径。**代码里没有任何按 `source` 分支的逻辑**（有用例断言 `RiskInputs` 无 `source` 字段 + 引擎源码无 `os.environ`/`now()`）。

### 3. 迁移 `db/migrations/0024_fin_paper_sequence.sql`

M2 实测发现 **M1 的 `0023` 漏授了序权限**：表权限给了、`BIGSERIAL` 主键背后的序列没给，paper 一写 `fin_cash_ledger` 就 `permission denied for sequence fin_cash_ledger_entry_id_seq`（只在第一次真 INSERT 时才现形）。`0024` 补齐四处序列，并加 `ALTER DEFAULT PRIVILEGES` 让**以后新加的 fin_ 表自动覆盖**。自检现在也校验序列 USAGE —— 这类遗漏以后在启动时挡下。

> 迁移只加不删：`0023` 一字未动（M1 报告要求）。

### 4. 编排与部署件

- `docker-compose.yml` 新增 `paper` 服务（镜像 `…-paper:${FIN_TAG:-latest}`、`127.0.0.1:${PAPER_HOST_PORT:-8200}:8000`、`depends_on: postgres healthy`、`PAPER_MODE: PAPER`）；**默认文件零 `build:`**。
- `docker-compose.dev.yml` 加 `build:` + 源码挂载（本地开发）。
- `.env.example` 补 `FIN_TAG` / `PAPER_HOST_PORT` / `FIN_PAPER_PASSWORD`，并在 `HUNTER_INTERNAL_KEY` 旁注明 paper 用同一把口令。
- `scripts/fin_provision_paper_role.sh`：给运行期角色设密码（`0023` 故意不写密码，密码不进仓库）。

## 二、偏离方案的决策与原因

### 偏离 1 · 账本仍在应用库；「唯一账本」由**角色 + 启动自检**兑现，不是独立库

沿用 M1 偏离 1（`app.migrate` 一个文件一个事务，`CREATE DATABASE` 建不出来）。但把设计意图做得**比独立库更可机器验证**：`paper` 用 `fin_paper_rw` 连库，**启动自检逐表断言「追加表上不能有 UPDATE/DELETE」**——把连接串指到管理员角色会**直接起不来**（见 §三 T-11 的实测输出）。这比「库名不同」更硬：库名可以骗人，GRANT 骗不了。

### 偏离 2 · `paper` 放在 compose 的 `fin` profile 下

任务书写的是「新增 paper 服务」。若让它默认启动，未 provision 的部署会得到一个**永远重启**的容器，破坏现仓铁律「`git clone` 后 `docker compose up -d` 就能跑」。故用 profile 隔离：默认 `up -d` 不受影响，要用时 `bash scripts/fin_provision_paper_role.sh && docker compose --profile fin up -d paper`。**服务本身、镜像、端口、depends_on 与任务书逐字一致。**

### 偏离 3 · 买入写三条流水（`freeze → buy → fee`），不是一条

风险第 6 条要求「冻结/解冻与持仓变动必须成对」。写成一条直接扣款就只是「可用减少」，**冻结这条口径没有任何代码在跑**。现在买入先把钱冻上、成交从冻结里划走、费用也从冻结里划走，**冻结在同一事务里归零** —— 对账里有一条 `frozen_zero_no_open` 盯着。

### 偏离 4 · 卖出只写 `sell/fee/tax`，券的冻结一期不建模

一期没有挂单（成交即成交），卖出不存在「券被冻住等成交」的状态。写一个永远为空的冻结在账上只会制造噪声。M3 有挂单排队时再补。

### 偏离 5 · 成交价 = 快照 `last_price`；M2 允许占位快照

撮合四步链路是 M3（`05 §3.2` M-12）。M2 只保证「成交价来自快照、每笔成交绑 `snapshot_id`」，限价只用于风控的价格校验。快照 `source` 传 `placeholder` 即可，M3 起换成采集到的真快照。

### 偏离 6 · `avg_cost` 不含费用；`confirm_t1` 只提供原语

成本口径写成「成交价加权、不含费」，避免 M2 就把一个未经用户确认的口径固化。T+1 日切（`sellable_qty = qty`）只提供 `ledger.confirm_t1()`，**何时调用由 M4 的时点工作流决定** —— 账本服务不该替调度做决定。

### 偏离 7 · 关掉 `/docs` 与 `/openapi.json`

实测这两个 FastAPI 自带路由**不吃 app 级依赖**，无密钥也返回 200，与「未带正确密钥的请求一律 401」冲突。全部关掉。

### 偏离 8 · 实盘字段黑名单是**精确匹配**，不是子串

子串匹配会把 `realized_pnl` 这类正常字段误伤。判据是归一化键名的精确集合，且递归扫嵌套 dict（有用例）。加新说法往 `config.LIVE_FIELD_DENYLIST` 里加，不另写第二份判断。

### 决策 · 入金是显式幂等端点，不做隐式补记

`POST /funding` 才把本金记成一条 `deposit` 流水。不做「第一次访问自动补记」—— 隐藏的写会让对账说不清。

## 四、遗留问题（按优先级）

1. **【高】`fin_*` 表 owner 仍是 `hunter`**（M1 遗留 #1）。启动自检挡住了「paper 被指到管理员连接」，但挡不住「别的服务用 owner 连库直接改账本」。M8 上演示站前要把 owner 迁给 `fin_paper_rw`（或改 `app.migrate` 支持事务外建库）。**账本侧的红线 7 仍是「自检级」而非「物理级」。**
2. **【高】`paper` 镜像未推 GHCR**。`docker-compose.yml` 里写的是 `…-paper:${FIN_TAG:-latest}`，M2 只在本地构建（`hunter-community-paper:dev`，38 秒）。**M8 必须发布镜像，否则 profile 一开就是拉取失败。**
3. **【中】幂等键（M-13）未做**。同一笔委托重放会产生第二笔成交。库表 `fin_idempotency` 已建好，`fin_project.version` 已每笔 +1 可作为乐观锁，但**命令级幂等键在 M13 才接**。
4. **【中】券的冻结 / 挂单排队（M-12）未做**：卖出不冻结券；订单没有 `pending` 态（一律 `filled`/`rejected`）。
5. **【中】T+1 日切靠 M4 调 `confirm_t1()`**：M2 提供了原语并有用例，但没有调度。线上若忘了调，持仓永远不可卖。
6. **【低】`avg_cost` 不含费用**；**占位快照**（`source='placeholder'`）在 M3 起要换成真快照，并补「行情断流 → 不成交」的分支。
7. **【低】`/docs` 已关**：M3 开发要看契约请读 `apps/paper/README.md`；要临时开就把 `openapi_url` 放回来（但记得它会绕过鉴权）。
8. **【低】`paper` 的 `depends_on` 不带 `api`**：paper 不依赖 api，是 api/fin-worker 调 paper，方向是对的；M4 接 fin-worker 时注意别接反。

## 五、下一里程碑（M3 · 快照与撮合）交接

**第一件事**：把 `apps/paper/app/ledger.py` 的 `place_order` 里「成交价 = 快照 `last_price`」换成 M-12 的四步链路（限价不劣才成 / 市价按对手价+滑点 / 不可成交则挂单排队 / 收盘未成撤单解冻），并把 `fin_order.status` 真正用起来（`pending` / `cancelled` / `expired`）。

**开工前必须知道的：**

- `fin_order` / `fin_trade` / `fin_snapshot` 的表结构已就绪；`snapshot_id` 是 FK，`fin_trade` 必须先有 order（**FK 顺序：order → snapshot → trade → cash**，M2 踩过一次）。
- 账本语义写在 `ledger.py` 文件头：`amount` = 该条对**现金总额**的变动，`Σ(amount) == 可用 + 冻结`。加新的 `kind` 时不要破坏这条不变量（对账 `cash_sum` 盯着）。`kind` 的 CHECK 在 `0023` 里写死（`deposit/freeze/unfreeze/buy/sell/fee/tax/adjust`），加新值要新迁移。
- 卖出的券冻结要新增流水语义（现在只有现金侧），**改之前先想「冻结/解冻与持仓变动必须成对」怎么在对账里表达**。
- 挂单一出现，`recon.frozen_zero_no_open` 就会因为 `frozen != 0` 而报警 —— 那时要把它改成「冻结 == 未成交委托的冻结额之和」。
- 测试跑法见 `apps/paper/README.md`；纯函数用例不连库，`PAPER_TEST_DSN` 一设就连库。**不要用 `docker exec` 进 api 容器跑长任务**（仓内铁律）。
- `m1-fin-pg`（5599）与 `m2_fresh` 是本轮起的临时设施，**不在 compose 里**，可以留着给 M3 省一次建库；`m2-py` 镜像（api 镜像 + pytest）同理。
