## 二、设计判断（偏离方案的地方与原因）

### 2.1 ⚠️ 本轮**动了后端**（方案 §5.0 只写了前端）—— 因为不动就只能写死

方案 §5.0 把公共件改动全放在前端，§5.1 却明确要求向导「选市场」卡片显示
**「本币 · 时区 · 交易时段（从 `fin_market_rule` 取，不写死）」** 与
**「规则差异（涨跌停模式 / 手续费 / T+N / 整手）」**，第 5 步的时点也要求
**「一律从 `fin_market_rule.points` / `sessions` 读，不写死」**。

而当时**没有任何前端可达的接口**能读到 `fin_market_rule` 的涨跌停模式 / 整手 / 可卖规则 / 时点。
要让界面按市场出这些参数，只有两条路：

| 选项 | 结果 |
|---|---|
| 在前端写死一张「三市场规则表」 | **违反红线 2**（不许拿 A 股规则顶替港美股）——同一件事写两处，早晚漂 |
| 把一个**只读**的展示子集从表里带出来 | 界面与执行读同一行数据，漂不了 |

选了后者。两处改动都是**只加字段**，既有语义一字未动：

- `GET /api/v1/fin/markets` 每项新增 `rule`（`fin_market_rule` 的 `points` / `sellable_rule` /
  `sellable_days` / `lot_rule` / `lot_fixed` / `price_limit_mode` / `market_order_supported` /
  `fee_model_version`）与 `constraints`（该市场六条硬约束文案，港美股如实标「未做」）。
  老前端读到的还是原来那份 —— `MarketStatusLine` / 切换器一个字节都没改。
- `GET /api/v1/fin/account` 新增 `market_accounts`（该项目**选中的**每个市场一行：本币本金 +
  最新一行收盘估值）。§5.2 要求卡片显示「各市场本币本金、当前净值」，而当时的 `account`
  只回当前那一个市场的账本；不补这个字段，前端就得为 N 个市场发 N 次 `/overview`。

> **没有**借这一轮改风控 / 撮合 / 账本 / 调度的任何逻辑（P1/P2 已定）。新增的两个函数
> 都是纯 SELECT，`market_rules` 查不到某市场时**不回落 A 股**（该市场在没有 `rule` 字段的对象里
> 以 `{}` 出现，前端显示「规则没读到」）。

### 2.2 「只列已选市场」放在前端做，后端不动

方案 §5.0 的落点就是前端。三个页面的 payload 里 `markets` 仍然是三个市场（**没改**），
由 `marketsOf(project)` 取 `/projects/current` 的 `markets` 数组、再用 `onlySelected()` 过滤。
好处是**历史遗留项目**（P1 之前建的、没有 `fin_project_market` 行）能退回老行为
（`marketsOf` 返回空数组 → `onlySelected` 不过滤 → 三个市场全列），
不会出现「这个项目的页签一个都没有」比空页更糟的状态。

### 2.3 `useFinPage` 加了 `skip` —— 否则会白打一枪、闪一下别的市场

三个页面的 URL 里带着 `?market=`，而「这个项目有哪些市场」要等 `/projects/current` 回来才知道。
不拦的话顺序是：按 localStorage 记住的市场打一枪 → 项目回来 → 市场被纠正 → 再打一枪。
**那正是方案 §5.0 点名要修的那个 bug 的弱化版**（「记着美股、这项目没有美股」的空页），
只是从「一直错」变成「闪一下」。`skip` 期间维持 `loading`，页面照常显示加载态。

### 2.4 跨市场汇总的显示条件收紧到「已选 ≥2」

P2 §六.3 把这条留给了界面阶段（「是否只在 ≥2 市场时才出，留给界面阶段一起定」）。本轮定了：

- 总览页的「跨市场合计（折人民币）」那一行、汇率来源说明、`comb.by_market` 分列 ——
  **只在已选 ≥2 时出现**；只选一个市场时那一行**整个不渲染**（把本币折成人民币不叫「跨市场合计」，
  那是凭空多出来的一个数字）。
- 每日报告页：`market='MULTI'` 的那份聚合报告**只在已选 ≥2 时出现**；单市场项目若最新一份恰好是
  MULTI，页面**自动改看最新一份本市场的**（不是一个空页，也不是把 MULTI 当「今日报告」）。

### 2.5 「买入 ST」按市场出，且**明说「不适用」而不是悄悄删掉**

任务书要求港美股**不出这条**（ST 是 A 股的特别处理标记）。实现是：A 股在硬禁枚举里带上
「买入 ST 与退市整理期股票」；没选 A 股时**那句枚举里没有它**，但下面另起一句说明
「你这次没选 A 股，所以「买入 ST」这条**不适用**」。
—— 悄悄删掉会让用户以为漏了；写清楚才是「按市场出」。

### 2.6 向导的「一键照抄推荐参数，直接去确认」捷径删掉了

原来第 2 步有两个按钮，其中一个直接跳「确认开启」。**选市场现在是必答项**，
留着这条捷径就等于替用户默认做 A 股 —— 那正是本轮要修的东西。所以只留一个
「下一步：选做哪几个市场」，且第 3 步未选时「下一步」禁用。
