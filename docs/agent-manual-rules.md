# 个人规则编辑与手动回测

2026-09-28：涨停后强势整理、涨停三阴方向增加规则编辑和手动回测。

- 参数、版本和最近十次回测写入 agent_meta 的 manual-rule:用户:方向，所有接口要求登录并按身份读取。为什么：公共纸上交易数据属于共享研究，不能由任意登录账号改写其他用户的结果。
- 编辑金额、持有天数、板块、均线、整理幅度和量能条件；核心信号和费用口径固定。保存使用版本检查，防止两个窗口互相覆盖。
- 每次回测冻结完整参数快照；修改尚未保存时禁止启动。结果独立展示，不能拿旧交易统计装作新规则的统计。
- 一次最多一年，数据库锁限制全站一个手动回测；任务状态持久化。进程中断后刷新能识别失败并重跑。
- 全池逐日计算，不能复用原固定预筛池：放宽参数后旧池可能遗漏符合新规则的股票。
- 净收益含费用及期末持仓市值；胜率按扣除双边费用的已平仓周期计算。整股、收盘价、无滑点及当前股票池的既有研究局限在界面说明。
- 回测日期必须处于已有日线范围，不自动补造缺失数据。上线必须测试保存版本、启动、进度与完成结果整条链路。
