# 大厅日线研究策略

2026年10月9日。策略键为tq_daily_v1加玩法名，状态为模拟盘研究版。

五族独立规则：趋势跟随、布林带均值回归、龙头突破、板块内动量轮动、超跌确认修复。价值、高股息与事件策略缺少时点化业务数据，禁止新入场，保留存量账户止损及可计算的ATR保护。

TqSdk skill用于研究规则，不直接执行模型生成代码。信号源使用按市场隔离的rs_daily完整日线窗口；旧klines存在异常OHLC，不能混用。A股与港股使用既有腾讯采集器补齐窗口，完整日线刷新接入现有开盘前候选生成流程，不另建调度器。行情源限流或校验失败保留缺口，上一交易日缺失则等待。

规则、仓位参数和源码一起计算指纹，API、worker以及登记策略必须一致。策略切换通过strategy.submit与control.activate_candidate，保留旧条目、配置日志和回滚依据；不覆盖原账本。源码变化需要发布新的登记版本。

交易数量受ATR风险预算、股票及组合暴露、现金、真实交易单位与原账户最小金额共同限制。不强行补到下限，不填缺失因子，不回退样例买单。现有最小订单金额可能高于新策略单股允许金额，因此产生等待是有效结果。原账户止损、止盈、持仓期限继续限制研究策略；持仓期限按完整交易日计数。原账户约束与模板中的默认值共同生效，不放宽已有风控。

同股占用在paper订单事务中再次检查，持仓和买单按项目去重计数，三位上限，禁止重复买入。新日线策略交易通过事务咨询锁串行检查。卖出不受买入经验限制；无可卖量或同标的在途委托时等待，不能假造成交。

回测读取真实日线、实际账户参数及市场费用模型，并加做费用和滑点双倍压力测试。信号收盘后最早下一开盘成交，另有同候选池整单位等权持有对照。历史日内保护退出、历史占用、历史成分和公司行动尚未完整重建，结果只用于研究与技术验证，不能称为独立样本外验证。保留所有失败、零交易和待数据结果。

## 操作入口

- api/scripts/collect_tq_daily.py：默认只采集快照，显式--apply才写既有rs_daily。
- api/scripts/backtest_tq_daily.py：只读回测，输出全部账户结果，支持外部真实行情快照。
- api/scripts/activate_tq_daily.py：默认预演，显式--apply经唯一入口切换；--rollback读取备份切回原策略。
- api/app/routers/fin_data.py：内部鉴权的stock-strategy/inputs只读入口。

代码镜像到开源仓的通用引擎、适配器及账本保护；开源当前未完整移植SaaS大厅档案和候选表，镜像提交不表示开源线上大厅已经启用。不能为了调用新接口伪造缺少的选手或候选表。

为什么保留研究标记：有交易的账户不等于参数有效，首轮的交易覆盖与历史假设不足以证明长期表现；只有完成独立验证才能升级策略状态。
