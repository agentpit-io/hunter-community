# 创建策略的统一入口

2026-09-29：用户确认「新建研究线」就是「创建策略」。研究台保留一个创建策略按钮，直接展开原有真实保存表单；名称、思路、规则草案和股票池仍使用研究接口保存，不新增第二套策略对象。

表单置于按钮下方、研究卡片上方，展开时聚焦名称。旧预览地址在本机部署中转向 agent.html#view=research&create=1。

入口首次合并时只保存草案。2026-09-29 后续已接入真实 AI 逐条识别及受限个人策略回测，详见 [AI 创建策略说明](agent-builder.md)。按钮「保存策略草案」只保存，「保存确认版本并回测」才执行；不能把预览模拟操作或暂未支持的规则当成真实能力。

股票池下拉实时读取 /api/quant/screener/meta 与 /api/quant/screener/saved，分组展示系统预设和当前账号保存策略，遵循本浏览器魔法筛选器的隐藏预设记录。新版个人策略保存标识、市场及脚本快照；旧研究线 pool 文本保持原样。请求失败时保留能加载的一组并显示中文错误，可刷新重试；异步填充只更新下拉，不重绘或丢失其他草案输入。为什么：静态复制预设会漂移，保存失败的列表也不能伪装为空列表。
