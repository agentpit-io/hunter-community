# 筛选器日K市场标识（2026-10-09）

筛选器日K请求使用扫描结果所属市场，显式添加 .US 或 .HK；代码显示和 hit-days 仍使用原始代码。A股及没有市场参数的其他调用保持原路径。已有市场后缀不重复追加，BRK.B 等代码保留完整。

为什么：扫描覆盖全市场，自选股登记缓存只覆盖部分标的；裸 PLTR 曾因未识别市场返回空数组，而 PLTR.US 能返回真实日线。不能把自选股缓存当成全市场目录。

日K缓存按完整符号和根数隔离。扫描当天蓝线补标复用同市场同根数数据，避免重复拉取和口径不一致。表格市场取 resultScan.market，不能因用户切换输入市场而改变已有结果所属市场。

验证：node web/public/strategies/kline_market_check.js（开源版前缀 apps/）及同目录 render_check.js；上线后调用真实 PLTR.US 日K。未完成登录后鼠标悬停的人工验收。
