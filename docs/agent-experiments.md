# 小鹿实验助手（2026-10-09，第一版）

## 产品边界与原因

这是借鉴微软 RD-Agent 的“假设—实现—实验—反馈”流程建立的受约束实验助手，尚未集成 RD-Agent 包、Qlib、新因子生成或模型训练。先复用既有执行路径，因为任意生成代码、同时改变多项参数会增加审计成本并放大过拟合。

入口：`strategies/agent.html` 研究台的“实验助手”。第一版仅支持 A 股 `limitup` 涨停后强势整理，以创建时公共方向的完整参数为固定基准。用户输入研究目标、放弃条件及最多一年日期，先查看 AI 候选，再确认运行基准与全部候选。不会自动应用、写公共策略、个人规则或交易账本。

AI 仅从后端菜单选最多三个候选，各只改变一个买入字段：整理幅度预设档位、均线多头或连续缩量开关。金额、卖出、板块、费用、涨停门槛和止损均不变。已有相同值不允许选择。AI 只输出编号和中文假设理由；额外参数、代码、未知/重复编号、数字或英文散文理由均拒绝。数值和结果来自后端，复用统一 JSON/语言守卫与 `screen_nl.model_name`。模型失败不造假候选。

## 状态、预算和隔离

- API：`/api/quant/agent/experiments` 列表、创建、详情、确认运行、停止；所有者仅来自登录身份。
- 使用已有 `agent_meta` 的 `experiment:<uid>:<id>` 和 `experiment-index:<uid>`；无数据库结构变更。全部规划、失败、停止与完成记录保留；列表显示最近五十条，旧编号仍可读取和下载。
- 每账号本方向最多二十次 AI 设计、二十次预留试跑。确认时一次预留基准与候选次数；失败、停止和未执行的预约不返还，避免无限试探。不自动重置，不代表独立模型数量，也不知道用户外部试验。
- 固定 Linux 子进程执行，不运行用户代码。实验锁限制全站一项；回测共用个人回测锁 `719280061`，避免与手动/创建策略回测争用。API 只启动和监督进程。
- 规划三分钟、整批回测三十分钟；监督线程在宽限后杀掉失控进程并回收。数值库线程限制为一，暂未提供独立容器、内存配额或 cgroup 隔离。
- 停止为持久标记，在规划返回/回测进度检查时生效，网络调用和行情载入不立即中止；关闭窗口不停止任务。记录超过三十秒且锁无人持有时标中断，保留已完成结果，未完成数字不填零。

## 快照与研究口径

每批载入一次行情，截取研究区间和六根热身 K 线，保存实际计算使用的日线、基准、代码和当时名称。全部候选使用同一份只读输入、相同资金，从空仓分别计算。

逐行 JSON 的 gzip 快照按账号哈希及实验编号保存，缺失值为 null，不覆盖同编号文件；元数据记录 SHA256。默认 `/var/lib/hunter/experiments`，compose 以 `hunter_experiments` 具名卷持久保存。自定义运行可设 `HUNTER_EXPERIMENT_DIR` 为持久可写目录。备份须同时保存数据库和该卷，否则不能恢复实际输入。快照是已有复权修正后的引擎输入，不能称为原始数据。

任务保留完整参数、规则和执行文件指纹、模型用量、试跑序号、日期、状态与完整逐笔结果。代码变化后拒绝执行旧草案，需重新创建。代码文件自身需依赖 Git 提交和镜像保存。

初筛由后端 `CRITERIA` 保存进任务：基准与候选各至少三十笔平仓、一百二十个交易日；候选净收益为正且高于基准、回撤不更差。仅标“可继续研究”，缺样本或失败标“证据不足”，不称赚钱概率/统计显著/样本外通过。基准失败整批失败，部分候选失败明确展示。放弃条件是事前文本，不由 AI 自动解释执行。

仍沿用同日收盘信号按收盘价成交、无滑点、当前股票池及 ST 名称等限制。快照提高复现能力，不证明历史时点可见性、不消除幸存者偏差；未新建封存测试集和查看审计，不以现有过拟合分数为优化目标。

## 验证与上线限制

后端覆盖白名单、单字段变化、身份隔离、预算/重复启动、代码变化拒绝、中断恢复、工作进程状态及快照往返后的真实引擎结果一致。数据库测试使用隔离替身，未验证真实 PostgreSQL 并发。

仅含本次暂存内容的干净源码包在 Windows 隔离环境和 hermes 独立临时目录的 Linux 环境均通过 126 项测试；没有改动线上代码或数据库。Windows 核心依赖已按项目版本对齐。Linux 测试使用现有运行时及临时 pytest 目录，模型、数据库、行情连接均隔离。

完整 CI 发现日期边界直接引用时区名违反仓库 L02 单一来源约束，已改用 `market_time.market_tz('a')` 并补回归。首次完整 Linux 运行另发现调度测试在最小启动环境下没有任务、scheduler 时区字面量及 A 股日线路由测试失败；此前 `8c1d495` 的 CI 已失败。本功能定向通过不等于全仓 CI 通过，上线前仍需核对完整检查。

`agent_experiments_check.js` 真执行渲染器，检查缺数、真实零值、转义和状态；`agent_experiments_browser_check.cjs` 使用隔离 API，在无头 Edge 检查创建、确认、历史重开、390px 布局。它不等价于真实模型或登录生产网站验收。既有 `render_check.js` 通过。

Linux 虚机 `192.168.64.10` 连接超时；fin-r1 主机指纹变化未核实，不能绕过。真实模型、真实行情、生产库并发、卷权限、容器重启及部署后三步尚未验证。上线前使用完整提交镜像、挂实验卷，实测候选生成—确认—停止—完成/失败—重启恢复，不能只看 HTTP 200。

SaaS 当前缺少对应小鹿业务链路，本次仅接社区版，不宣称 SaaS 已接入。
