## 为什么补这些数据

原快照293434条记录不能直接解决时点化问题。补入港股19标的44条原始年度EPS记录、A股27标的106条原始年报EPS记录，分别41与54个标的年度组合，保留原件SHA256、披露元数据、页码与摘录。全部检查年度、日期和哈希；复杂负号、股本重述及宽表案例做视觉核验，不声称每个表格都人工逐页审核。

比亚迪2024原始EPS13.84不能用后来调整后的4.61回填；吉利2024原始EPS163.80分换算1.638元；万科2024基本EPS括号4.17代表−4.17，不能误取上一年1.03。原始证据与QA截图随本目录保存。

另补真实CNY/HKD、USD/HKD历史汇率，以及00073、00686的Yahoo历史复权行情。源OHLC不一致记录剔除，不填造。600837旧行情没有测试期报价，其候选池缺口保留，券客、掮客、镖局覆盖不完整，但可用标的实际回测。

## 验证与限制

完成日期隔离、分红跨源去重、负盈利拒绝、未知港股披露日期拒绝、财报事件确认测试及9项原策略回归测试。两组回测所有成交严格晚于信号日；955条有参考数据证据的成交通过可知日期检查。112条曲线末值与完整报告收益一致。

单头寸开仓上限25%且服从账户更严格约束，保留ATR风险预算、整交易单位、A股5000元最低订单、次日开盘近似成交及标准费用。双倍成本对照没有重新调参。

本研究用复权价格净值代理，不额外重复加现金分红，尚未重建完整未复权公司行动资金账本。不能据此宣称派息到账、拆合股、配股逐笔会计正确。当前候选池有生存者/选样偏差，费用采用当前版本，未验证历史费率分段、盘中成交、实际订单簿、多账户占用和投研委员会，也没有样本外检验。部分年度盈利仍使用供应商晚更新日期进行保守隔离。
