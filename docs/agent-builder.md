# AI 创建个人策略与逐条确认

2026-09-29。入口沿用研究台「创建策略」。输入策略思路和规则草案，选择筛选器股票池，点击「AI 整理为规则」。每条可编辑原文、类型和参数，可只重新识别一条；模型失败保留原规则。修改某条只撤销该条确认，修改整体原文撤销全部确认。模型返回期间发生编辑，不用迟到响应覆盖用户输入。

## 规则和执行必须一致

`agent_builder.SCHEMA` 是参数范围及中文标签来源，前端据此生成表单，后端再次校验。首版支持前期高点突破、均线上方、量能倍数、固定止损、固定止盈、均线退出、持有天数退出、最高收盘价回撤、仓位与风险上限。买入规则为且；当前第二版退出按优先级，可分阶段卖出，仍不加仓。

AI 只返回受限 JSON，不能写代码。每条必须引用用户原文，所有数值必须能在引用原文中找到；未给参数、超范围及不支持的复杂规则转为 pending。模型不能确认规则。除“一半→50%、全部→100%、明确比均量增加40%→1.4倍”的受控转换外，中文数字或模糊描述需要用户补为明确数字。用户还需核对原文无遗漏；数字来源验证不能证明模型完整理解语义。

单条重新识别仅发送该条原文，返回恰好一条，不改其他条。所有规则确认、必需的买入/止损/仓位/单笔风险/持仓数齐全，并确认交易假设，后端才接受回测。

## 真实能力范围

首版新策略回测只支持美股和可还原历史字段的普通筛选脚本；序列脚本股票池、其他市场、分批止盈、加仓、盘中止损及任意 Python 不支持，不能被 AI 静默替代。不自动启动每日纸上交易或自动优化。

信号在当日收盘计算，下一交易日收盘模拟成交；停牌订单等待有报价的交易日。止损同样延迟，不能宣称最大实际亏损被止损百分比保证。单票股数取资金上限、单笔风险和可用现金三者最小值，费用另扣；信号竞争使用代码顺序。成交滑点及初始资金由用户确认，费用复用美股阶梯式口径。

期末未平仓按最后可用收盘价估值，不虚构已平仓收益。未来数据不进入指标切片；历史股票池仍有当前入库范围的幸存者偏差，复权修正使用当前锚点。缺数据为未知并统计次数，不以零或模拟行情补齐。最长回测一年，日期不能超出已入库基准日线。

## 持久化及接口

使用 `agent_meta` 的 `builder:<user_id>:<uuid>`，不改公共 branch 账本。保存采用版本号乐观锁与事务锁，保留旧版本，回测绑定完整规则、原文、股票池脚本、成交口径和设置快照及 SHA256。筛选脚本在加载与保存间变化会拒绝保存，要求刷新。已保存的旧结果不会随筛选器后来修改而变化。

- GET /api/quant/agent/builder：个人列表、规则 schema、数据日期范围。
- POST /api/quant/agent/builder/recognize：整体或 single 单条识别。
- POST /api/quant/agent/builder：保存新策略或版本。
- GET /api/quant/agent/builder/{id}：个人策略、旧版本和回测结果。
- POST /api/quant/agent/builder/{id}/backtest：提交确认版本的后台回测。
- DELETE /api/quant/agent/builder/{id}：删除自己的个人策略，保留旧快照，运行中不能删除；已删除策略不能读取、覆盖或继续回测。
- DELETE /api/quant/agent/builder/research/{key}：从当前账号研究台移除该卡片（含旧版待写引擎草案），历史公共账本不删除，其他账号不受影响。为什么：默认研究线是共享回测来源，直接删除会破坏其他研究线的对照组。页面确认明确说明此口径；不提供恢复入口。

身份必需；AI 复用筛选器 AI 次数，模型未配置或调用失败退次。回测与既有个人回测共享数据库资源锁；进程中断后读取会将失去运行锁的任务标失败，不永远显示运行中。结果保存在个人策略中，可刷新或下载完整快照、净值与每笔交易。

## 验证

### 多语言编辑器（2026-09-30）

识别结果位于左侧编辑区，与右侧AI助手并排；原文与识别结果分标签保留，识别或加载后自动显示结果。规则默认紧凑行展示原文摘要、类型/参数和确认状态，旁边提供编辑、AI重新识别、删除；编辑时只展开当前一条，手动新增自动展开。长列表在左侧滚动。为什么：大量完整表单会挤到页面底部，让用户误以为识别结果没有生成；切换视图不得丢失原文、规则或确认状态。

整体 AI 识别的加载、完成、失败提示统一放在右栏按钮正下方；等待时转圈、按钮禁用并显示「正在识别…」，所有结束路径都停止动画并恢复按钮。尊重减少动态效果的系统设置。为什么：远离操作位置的提示容易被误认为没响应，造成重复提交。保存和回测状态仍留在对应规则区域。

识别改用独立 AsyncOpenAI 连接、禁自动重试、总等待90秒，按账号登记任务；提供 GET /recognize/status、POST /recognize/cancel。停止会取消异步任务并关闭客户端连接、丢弃结果、释放账号占用，不能停止其他账号；刷新后可以找回停止入口。最多同时四个请求。为什么：旧版全局锁加同步模型调用在连接失败重试时长时间占用，浏览器结束等待也无法解除锁。本地单API进程使用进程内任务表，多进程部署须先改成共享任务调度。主动停止不承诺退还上游已发生的模型费用，也无法保证供应商立即停止内部计算。

模型故障须区分授权、额度、限流、地址/模型、连接、响应格式和截断，不得统称「连接异常」。SDK自动重试仍禁用；仅连接异常或5xx在90秒总时限内显式重试一次，超时不重试；明确拒绝JSON模式参数时才降级普通模式一次。为什么：已绑定服务不代表每个请求都成功，宽泛异常提示会误导用户反复更换正常配置。日志仅记异常类型/HTTP状态，不输出密钥、上游正文或策略文本；无效JSON、空choices和截断不得作为交易规则进入回测。

创建页的「策略描述」为选填简介，前后端限制一百字，不参与交易规则识别，也不因修改简介撤销交易规则确认。为什么：简介只是展示信息，不能把旧版完整策略原文截断后混入简介。

规则编辑器位于左侧，支持自然语言（中文、英文）、Python、JavaScript、ThinkScript、Pine Script、C++、Rust、My语言作为输入。右侧 AI 助手提供自由输入和预设；点击预设只填入右侧内容，不发模型请求，用户再点击识别。左侧原文与右侧输入合计最多六千字。语言选择传入模型提示词，但不赋予代码执行能力；不能准确映射的逻辑仍为 pending，不能回测，不能把任意脚本宣称为原生可执行。

保存、历史版本和回测快照保留 description、source_language、source_text、assistant_prompt。旧策略没有这些新字段时，完整 source_text 放回规则编辑器，简介留空，语言默认自然语言。代码或 AI 输入变动撤销确认；识别期间语言或原文改变时，不覆盖用户的新编辑。单条重新识别继续独立执行，不改变其他行。

新增 test_agent_builder_editor.py 覆盖语言白名单、原文数字校验、简介边界、保存版本与旧请求兼容；浏览器覆盖预设不请求、双栏与窄屏、空简介保存、语言传递、新旧策略加载。

`tests/test_agent_builder.py` 验证参数、数字来源、确认、信号时序、延迟止损、手续费、资金与风险上限、账号键隔离；`tests/test_agent_builder_router.py` 验证身份、请求和额度。

`agent_create_check.cjs` 浏览器验证逐条编辑、确认失效、单条识别隔离、失败保留、回测确认闸门及窄屏。AI 响应在该浏览器测试中模拟，仅用于测试，不写生产规则。真实模型调用及真实日线回测应另外记录，不能拿模拟测试冒充 AI 联调。

连接异常及5xx最多重连两次，间隔一秒、三秒；每次新建且关闭独立客户端，建连八秒超时，响应七十五秒，整体仍受路由九十秒截止和用户取消约束。只重试建连超时，响应超时不自动重复提交。认证/额度等4xx不自动重试，明确不支持JSON模式的降级仍一次。若兼容网关在 JSON 模式下直接关闭连接，首次 RemoteProtocolError 会切换为普通请求模式再试一次，普通模式仍要求只返回 JSON；不会把同一个 JSON 模式请求盲目重复三次。识别提示词只发送类型、分类和参数范围，去掉回测展示模板，减少长文本触发上游断连的机会。为什么：快速原连接重试恢复窗口太短，且旧日志无法区分中间网络断连；长上下文携带无关模板会增加网关关闭连接的概率。新日志只记录异常类链，区分DNS、证书、代理和连接关闭，不泄漏正文、地址、凭据。外部网络故障不能承诺永不发生，失败保留输入和已有规则。

## 创建草稿刷新保护（2026-09-30）

创建页输入不能仅保留在DOM。当前浏览器localStorage按JWT主体账号分键保存本机草稿，记录名称、描述、左右原文、语言、识别行及确认、展开编辑行、结果标签、股票池标识、回测设置和已保存策略id/version；不存令牌，不替代服务端版本保存。输入同步写入，识别/加载/删除等程序修改也保存；页面刷新、收起再打开、切换看板再回来均恢复。为什么：原先重新渲染就清空内存表单，尚未点击保存的输入没有任何恢复来源。

创建界面将create=1写入URL，刷新保持展开；主动收起移除标记但保留草稿。恢复不请求模型、不启动回测；保留每条已确认状态，但整体成交口径必须重新确认。股票池异步加载完按kind/id选回，不使用数组下标；失效选项不能默认替换成其他池。清空本机草稿需确认，只清编辑器，不删除保存的策略或历史结果。

无法写本机存储时显示失败并在离开前提示，不假称保存成功；损坏草稿不自动删除。该功能仅同浏览器、同站点、同账号有效，清理浏览器数据后不能恢复；此前未落盘已丢失的输入无法凭空找回。agent_draft_check.cjs覆盖刷新、状态、股票池、收起、切换看板、账号分键、配额失败及清空；不调用真实AI、不写用户策略。
