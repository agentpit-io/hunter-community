## 第 1 章：产品简介与 3 分钟首次上手（装好后第一步干什么？）

### 1.1 首次打开设置向导与大模型配置

- **① 解决你炒股的什么痛点？**
  很多股民装好 AI 软件后一头雾水：不知道去哪填大模型 Key、不知道行情通不通、怕配置太复杂。猎鹿人把所有开关集中在同一个设置面板里，填好 API Key 点一下测试就能用，A 股/港股/美股公开行情开箱即通。
- **② 去哪点、怎么操作（按钮级指引）**
  - **第 1 步**：在浏览器打开猎鹿人首页，点击左下角头像或直接访问 `/settings?tab=llm` 进入 **「设置 → 大模型与偏好」**；
  - **第 2 步**：选择你顺手的大模型服务商（支持 DeepSeek、通义千问、OpenAI、Claude 或本地 Ollama），粘贴你的 API Key 并点击 **「保存并测试连接」**；
  - **第 3 步**：确认右上角状态灯变绿，即可点击顶部 **「返回对话」** 开始看盘问股。

### 3.1 自选股盯盘与盘中突发异动解释（停牌票诚实显示 `—` 绝不乱填 `0`）

- **② 去哪点、怎么操作（按钮级指引）**
  - **第 1 步**：在「投研工作台」（`/workbench`）点击第二个标签页 **「自选股工作台」**；
  - **第 2 步**：查看自选股实时行情列表——注意看正常交易票（如贵州茅台 `600519.SH`、腾讯控股 `00700.HK`）的实时涨跌与估值，以及异常/停牌测试票（`600898.SH`）诚实展示的 `—` 与状态说明；
  - **第 3 步**：当某只自选股盘中出现放量急涨或跳水时，点击 **「盘中异动归因解释」** 按钮，系统会立刻结合最新公告、板块联动和资金流给出多维度原因排查。

  - **第 3 步**：画面右侧立刻滑出 **「公告 PDF 原文溯源抽屉」**，直接高亮展示该结论对应的第几页、第几段原文条款，核对完点右上角关闭即可继续看盘。

## 第 7 章：普通股民最关心的 6 个问题（安全承诺与常见排障）

### Q1：我的持仓、交割单和聊天记录存在哪里？会被上传到别人服务器吗？
- **答：100% 存在你自己的电脑/服务器本地数据库里。** 猎鹿人是自部署的私有投研工作台，你的持仓账本、CSV 交割单、交易日志和 `fin_memory` 复盘经验库全部保存在本地。除了你在对话时发给大模型 API 的必要提问上下文外，没有任何第三方平台能偷看你的持仓底牌。

### Q2：接入持仓或打开“智能体自动炒股”后，AI 会不会乱点把我的真钱股票卖掉？
- **答：绝对不会，物理级 0 风险！** 猎鹿人从底层代码设计上就遵循 **「只做投研与模拟、绝不碰实盘下单」** 的铁律：
  1. 合作券商连接器只有 **只读权限（Read-Only）**，代码里根本不存在实盘委托买入/卖出或银证转账接口；
  2. 「智能体自动炒股」（`/finance/overview`）跑在 100% 独立的虚拟模拟盘账户上，哪怕点错任何按钮，也绝不会动你实盘账户里的一分钱。

### Q3：为什么有的股票（比如 `600898.SH`）价格或市盈率显示 `—` 横杠，是不是软件坏了？
- **答：这不是软件坏了，而是猎鹿人专门设计的「诚实缺数保护机制」！** 当一只股票处于停牌、退市整理、亏损导致无市盈率（PE 为负）或数据源暂时没有有效报价时，很多劣质软件会乱填 `0.00` 甚至让 AI 随便编一个数，极其容易误导股民。猎鹿人严格规定：**拿不到真实有效数据时必须诚实显示 `—` 并注明原因，宁可留白提醒你核实，也绝不拿假数字骗你。**

### Q4：大家都说 AI 大模型经常算错加减乘除、胡编股价，猎鹿人怎么解决这个问题？
- **答：靠「底层确定性引擎 + 数字回读校验（Numeric Readback）」双保险：**
  1. 所有的技术指标（56 项）、基本面财务比率（90 项）、ETF 定投收益率（XIRR）和量化回测，统统由 Python 确定性数学引擎算好标准答案再喂给页面，**绝不让大模型心算数学题**；
  2. 盘前晨报与投研卡片右上角都有 **「数字回读校验通过」** 标志——系统会自动把生成文字里的每一个价格、涨跌幅与底层接口原始返回值逐字比对，对不上立即拦截重算。

### Q5：如果打开页面提示“大模型未响应”或某只股票行情没刷出来，我该怎么排查？
- **答：按下面 3 步，1 分钟就能自己搞定：**
  1. **查大模型 Key**：去 `/settings?tab=llm` 点一下「测试连接」，看看是不是 API Key 填错了或者余额用完了；
  2. **看股票代码后缀**：输入代码时尽量带上市场后缀（上交所 `.SH` 如 `600519.SH`、深交所 `.SZ` 如 `000001.SZ`、港股 `.HK` 如 `00700.HK`），避免同名股票混淆；
  3. **看数据源状态灯**：在 `/workbench` 顶部或 `/settings` 查看行情源状态，如果是周末或节假日休市，系统会自动显示最近一个交易日的收盘截面数据并标注时间戳。

### Q6：换电脑或者重装系统时，怎么备份和恢复我的自选股、持仓和复盘笔记？
- **答：非常省心。** 你所有的数据都保存在项目目录下的本地数据库卷（PostgreSQL `pgdata` 卷）和 `user-skills/` 文件夹中。平时只需在设置页导出持仓与交易日志 CSV 留底，或者直接备份项目数据库目录，换新电脑后一键导入即可完整接续之前的全部投研记录。
